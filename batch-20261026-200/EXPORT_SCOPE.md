# Export scope

This package contains 200 authored mathematical contributions and their verification records. The destination is the authenticated user gavenren's existing public reproducibility repository; GitHub confirmed matching owner ID 206281466 and admin/push permissions.

Raw third-party source manuscripts and source caches are excluded. Public sources are cited in each contribution. Local absolute paths in JSON metadata are normalized to batch-relative paths. Manuscript and checker bytes are preserved.

The final-byte audits in qualified_audits are the final scoped reviews. The root_audits directory preserves earlier historical checks; some hashes refer to versions before the final edits. None of these records claims formal verification, human peer review, novelty certification or editorial acceptance.
