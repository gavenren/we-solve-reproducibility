A matching upper bound uses only integer weights and zero biases. At one level, replace a pair of real affine readouts a,b by three nonnegative channels

Its width is O(d) at each level, its total size is polynomial, and every connection/output weight is an integer. Padding to a balanced binary tree or carrying unpaired readouts handles arbitrary d.

**Bias qualification.** If the source's lower-bound presentation is taken in a zero-bias homogeneous model, it still yields the assertion here with arbitrary fixed biases. Suppose a finite network with integer connection matrices and real biases computes a positively homogeneous function F exactly. Evaluate it at tx, divide each layer's activations by t, and let t→∞. Inductively σ(tz)/t=σ(z) and continuity imply that the limit is the network with the same connection matrices and all biases set to zero. The output bias vanishes as well. Since F(tx)/t=F(x), that homogeneous zero-bias network computes the same F. Integer connection weights are preserved. This argument concerns exact representation on all of R^d, not approximation on a bounded sample.
