# The iterated-logarithm coloring lower bound from shift graphs

Problem: TOP-30005020  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** For deterministic LOCAL algorithms on consistently oriented n-cycles with distinct identifiers from [n], prove that proper three-coloring requires at least (log* n−2)/2 rounds up to the trivial wraparound case. This gives the sharp-order Ω(log* n) lower bound for the Δ=2 coloring subcase even when orientation and n are provided. It does not decide arbitrary-tree constant-round LCL solvability.

The lower-bound mechanism is Linial's classical neighborhood-graph argument; the source and priority are credited. We give a complete shift-graph proof, keeping identifiers and radius explicit. The deterministic LOCAL model allows unlimited local computation and messages, but in T rounds a vertex's output depends only on its radius-T labeled neighborhood. All cycle vertices have degree two and a consistent predecessor/successor port orientation; even knowing n does not reveal remote identifiers.

For integers r,N≥1 let H_r(N) have vertices all strictly increasing r-tuples from [N], with a directed edge
(a₁,…,a_r)→(a₂,…,a_r,b) whenever a_r<b. Proper coloring ignores edge orientation. H₁(N) is a complete graph and has chromatic number N. If H_r(N) has a proper q-coloring c, r≥2, define a color of each (r−1)-tuple u=(a₁,…,a_{r−1}) by the **set**
\[
 S(u)=\{c(a_1,\ldots,a_{r-1},b): b>a_{r-1}\}.
\]
There are at most 2^q such sets. For adjacent u=(a₁,…,a_{r−1}) and v=(a₂,…,a_r), the color c(a₁,…,a_r) lies in S(u), but lies in none of S(v): every r-tuple (a₂,…,a_r,b) is adjacent to (a₁,…,a_r). Thus S(u)≠S(v), including when S(v) is empty. We have constructed a proper 2^q-coloring of H_{r−1}(N).

Iterating, a q-coloring of H_r(N) implies
N≤2^{2^{⋯^{2^q}}}, with r−1 exponentiation steps. With log* defined as the number of base-two logarithms needed to reach at most one, this gives log* N≤r−1+log* q for N>1. There is no asymptotic chromatic estimate hidden in this step; it is a finite explicit recurrence.

Now suppose T rounds suffice for three-coloring every oriented n-cycle with identifiers [n], with n≥2T+3. Apply the local algorithm to the rooted ordered radius-T neighborhood whose 2T+1 identifiers are any increasing tuple from [n]; fill the other cycle positions with unused distinct identifiers. The output depends only on that tuple, its fixed center, the common port convention and n, so it defines a three-coloring of H_{2T+1}(n). Two adjacent tuples occur at adjacent centers in a single oriented cycle: their combined increasing segment has length 2T+2≤n−1 and can be completed with the remaining IDs. Correctness of the distributed algorithm forces their outputs to differ.

Using q=3 and log*3=2 in the recurrence yields log* n≤2T+2, hence T≥(log* n−2)/2. If n<2T+3, then T>(n−3)/2, which already implies an Ω(log* n) bound for large n; finitely many smaller n affect only an additive constant. This covers algorithms whose actual worst-case T depends on n. An identifier universe [n^C] with C≥1 contains these instances, so the same lower bound applies there. Randomized algorithms and their error probabilities are not covered by this deterministic proof.

The cycle has Δ=2, so three colors are exactly Δ+1. Since orientation and n are extra information, proving the bound even with those inputs is a valid lower bound when less information is available. It addresses growing n, rather than only the zero-round pigeonhole obstruction in the earlier report. Cole–Vishkin color reduction supplies the matching O(log* n) order in this bounded-degree setting; that upper mechanism is already developed in A1 and is not counted again here.

The source bundles a different meta-problem: given any finite LCL description on trees, decide whether a constant-round algorithm exists. A lower bound for this one cycle-coloring task does not solve that meta-problem, and cycles are not silently replaced by trees. No degree-dependent bound for arbitrary Δ or randomized complexity frontier is asserted. The added result is the full classical iterated-logarithm lower bound with a complete neighborhood realization and chromatic recurrence.
