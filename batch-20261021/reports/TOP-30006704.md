# SETH to logarithmic-dimensional orthogonal vectors, with every exponent paid

Problem: TOP-30006704  
Claim type: Conditional result  
Author: /root/hundred_algorithms

**Exact scope.** Full split-and-list reduction: a uniformly truly subquadratic deterministic bichromatic Boolean Orthogonal Vectors algorithm in every fixed logarithmic dimension would refute SETH. Includes the sparse-dimension conversion, list construction and quantified constant accounting. This is an established conditional fine-grained implication, not a proof of SETH or an unconditional OV lower bound.

Bichromatic Boolean Orthogonal Vectors asks whether two lists A,B of at most N vectors in{0,1}^d contain a pair with ordinary integer dot product zero. Duplicates are harmless. The following sufficient refutation premise is explicit: there exists epsilon>0 such that for every fixed c>0, an algorithm for dimensions d<=c log_2 N takes O(N^{2-epsilon}(log N)^{C_c}) deterministic bit time. Algorithms and constants may depend on c; epsilon is one fixed positive saving independent of c. Restrict epsilon to(0,1] by weakening it if necessary. The same conclusion follows from one uniform algorithm taking O(N^{2-epsilon}poly(d)) on all dimensions. A speedup epsilon_c tending to zero does not meet this premise.

**The exact reduction before sparsification.** Split n SAT variables into two sets with sizes floor(n/2),ceil(n/2). For every assignment a to the first half define a Boolean vector indexed by clauses: its jth bit is1 iff none of that clause's first-half literals is satisfied by a. Define b analogously for second-half assignments. A clause is false under the combined assignment exactly when both corresponding vector coordinates are1. Therefore
\[
 F\text{ is satisfiable}\quad\Longleftrightarrow\quad
                    \exists a,b:\ a\cdot b=0.             \tag{17}
\]
Each list has at most N=2^{ceil(n/2)} vectors. Constructing all entries costs2^{ceil(n/2)}poly(|F|,n) bit time, including writing them. There is no implicit free exponentially long table. The case of an empty clause yields a coordinate equal to1 in both lists and correctly prevents any orthogonal pair; an empty clause set is decided as satisfiable directly. Assignments on an odd split and repeated vectors cause no issue.

For fixed-width k, delete duplicate clauses and tautologies first, leaving at most O(n^k) clauses. Thus(17) already gives a polylogarithmic-dimensional reduction. To obtain the standard **constant-times-logarithmic** dimension, use the precisely credited Impagliazzo–Paturi–Zane sparsification lemma: for fixed k and alpha>0, produce at most2^{alpha n} k-CNFs whose disjunction is F, each with at most C_{k,alpha}n clauses, in2^{alpha n}poly(|F|,n) time. The constant depends on k and alpha, not on n. This deep source theorem is not reproved here.

Apply(17) separately to every sparse formula. Its dimension is d<=C_{k,alpha}n<=2C_{k,alpha}log_2 N, so fix c=2C_{k,alpha}. The hypothesized algorithm for that c takes
\[
 N^{2-epsilon}\operatorname{poly}(n)
  =2^{(1-epsilon/2)n+O(1)}\operatorname{poly}(n).
\]
The ceiling changes only a constant factor, since2ceil(n/2)<=n+1. Set alpha=epsilon/8 before choosing k's sparsification constants. The total time, including all sparse instances and vector writing, is bounded by
\[
 \left(2^{(1-3epsilon/8)n}+2^{(1/2+epsilon/8)n}
       +2^{epsilon n/8}\right)\operatorname{poly}(|F|,n).
\]
For0<epsilon<=1 the largest exponent is at most1-3epsilon/8. Constants and polynomial powers may depend on fixed k and c, which the SETH definition allows. The saving3epsilon/8 is independent of k. Therefore s_k<=1-3epsilon/8 for every fixed k, contradicting lim_k s_k=1. This establishes the stated implication with every reduction cost paid.

The split-and-list connection is established in Williams's primary constraint-satisfaction paper, Section5.1, and related OV work. The source of the exact sparsity parameter control is IPZ2001, not the mere fact that CNF has a short description. It is equally important not to reverse(17) into a proof of hardness without assuming SETH: the reduction is unconditional, but the lower-bound conclusion is conditional.

**Quantifier/model limits.** A separate subquadratic exponent at each dimension constant might provide only k-dependent SAT savings approaching zero and remain consistent with SETH. An algorithm with N^2/log N time has no fixed exponent saving. Randomized OV algorithms would address an appropriate randomized SAT hypothesis, not automatically the deterministic SETH in this prompt. Finally, unit-cost operations on whole vectors would change the model: the assumed OV running time includes bit input reading; in d=O(log N), this contributes only logarithmic factors to the displayed reduction. None of these distinctions is removed here.
