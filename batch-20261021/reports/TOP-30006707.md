# Width-five permutation programs are an exact reformulation of the formula target

**Exact scope.** The classical nonuniform NC¹ = polynomial-length width-five permutation-program characterization is reconstructed, including both simulations. Therefore a uniformly P-computable family separates P from the prompt’s nonuniform formulas exactly when it requires superpolynomial length in this specific width-five model.

An instruction selects one of two permutations of five symbols according to one queried input bit. A program's value is the ordered product of its instructions. Input bits may be queried repeatedly, in an order depending on the program, and the program description is nonuniform. A program α-recognizes f if its value is identity on f=0 and a prescribed 5-cycle α on f=1.

All 5-cycles are conjugate in S₅. Conjugating both choices of every instruction changes an α-program into a β-program without increasing its length. Reversing the instruction order and inverting each choice gives the pointwise inverse program. To complement f, multiply its program value on the left by α and use its inverse: αP^{-1} is α on f=0 and identity on f=1. The constant multiplier can be absorbed into the first instruction, so no extra query is needed.

There are 5-cycles a,b whose commutator c=aba^{-1}b^{-1} is a 5-cycle: for example a=(12345), b=(13542) under right-to-left composition. This can be checked by applying the four permutations to each of the five symbols. Suppose P,Q recognize f,g and have their outputs conjugated to a,b. Concatenating P,Q,P^{-1},Q^{-1} gives identity when either input function is false, and c when both are true. A final conjugation changes c to any desired output 5-cycle. Thus AND of two programs of length at most ℓ has length at most 4ℓ. OR follows by complementation and AND; these complement transformations do not increase length.

A depth-d fan-in-two AND/OR circuit with negations on input literals therefore has a recognizing program of length at most 4^d, by induction, starting from one-instruction literal programs. Sharing in the circuit causes no difficulty: subcircuits are copied when generating the program, and the length bound already charges those copies. The transformation is constructive in time polynomial in the output program length and the input circuit length; each instruction stores an O(log(n+2))-bit queried variable and two constant-size permutations.

Conversely, for any fixed width w, an instruction's selected map [w]→[w] has a constant-size Boolean encoding. Composition of two such maps is a fixed finite Boolean function and hence has a constant-depth, constant-size fan-in-two circuit depending only on w. A balanced binary tree multiplies ℓ maps in depth O(log(ℓ+2)), with O(ℓ) constant-size nodes. A final constant-size test determines whether the product is the designated output permutation. Thus polynomial-length constant-width programs are in nonuniform NC¹.
