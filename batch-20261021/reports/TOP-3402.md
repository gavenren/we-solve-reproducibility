# Quantified 2-CNF: elimination and compact winning strategies

Problem: TOP-3402  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** Fully quantified Boolean formulas with a 2-CNF matrix, arbitrary quantifier alternation and explicitly encoded variables are decidable in polynomial bit time. Inside-out width-preserving elimination also constructs polynomial-size circuits implementing existential winning strategies. This treats a substantial restricted PSPACE problem and does not decide P versus PSPACE.

Consider a closed prenex sentence Q_1x_1...Q_nx_n F, where F is a conjunction of clauses with at most two literals. Each variable is quantified once and every literal is bound. Constants, empty clauses and the empty conjunction are permitted. Variable identifiers and the complete prefix are part of input length L. Remove duplicate literals and tautological clauses, retain an empty clause as false, and discard repeated clauses. The number of possible remaining clauses is O(n^2), including units and the empty clause.

**Exact elimination identities.** Work from the innermost quantifier outward. For the current variable x, write the current CNF as
\[
 G\land\bigwedge_i(x\vee A_i)\land\bigwedge_j(\neg x\vee B_j),
\]
where G has no x and each A_i,B_j is empty or a single literal. No retained clause contains both signs of x. Existential elimination replaces the x-clauses by all resolvents A_i vee B_j:
\[
 \exists x\,F\equiv G\land\bigwedge_{i,j}(A_i\vee B_j).       \tag{2}
\]
For a fixed assignment to other variables, a positive x-clause forces x=1 exactly when A_i is false, and a negative clause forces x=0 exactly when B_j is false. A consistent choice exists exactly when no pair forces opposite values, which is precisely (2). If one of the two families is empty, the empty product is true and the one-sided requirements can all be met.

Universal elimination simply erases x or neg x from each x-clause:
\[
 \forall x\,F\equiv G\land\bigwedge_i A_i\land\bigwedge_j B_j.\tag{3}
\]
Indeed both assignments to x must work. In particular a unit x or neg x produces an empty clause under (3). These pointwise identities hold with all outer variables free; applying them in prefix order therefore preserves every quantifier dependency. Neither identity expands clause width beyond two. Remove tautological resolvents, merge duplicate clauses, and continue. After all variables have gone, absence of an empty clause is exactly truth of the sentence.

**Compact strategies, rather than an exponentially long table.** Retain the residual formula immediately before each elimination. Play the quantifier game in the original outer-to-inner order. At an existential x choose1 iff at least one saved positive x-clause has its residual A_i false under the already assigned outer variables. If none does, choose0. Formula(2) ensures that this choice cannot violate any negative x-clause whenever the already assigned outer values satisfy the eliminated residual. At a universal x, (3) ensures that either move preserves the corresponding invariant. Induction over the game therefore supplies a winning existential strategy when the closed sentence is true.

The saved formula for x contains only x and earlier variables, because all inner variables were eliminated. Evaluating the disjunction of falsified A_i requires a polynomial-size Boolean circuit. Connect these circuits in prefix order, feeding earlier existential outputs into later ones and treating universal moves as inputs. This gives a polynomial-size acyclic shared circuit family for the strategy, not a fully expanded decision tree. The dependence restriction is preserved: an existential output never reads a future universal move. The strategy circuits can also be checked against the elimination certificates.

**Encoding bounds.** At each stage there are O(n^2) distinct clauses; a deliberately loose implementation checks O(n^4) candidate pairs and uses O(log(n+2))-bit identifiers, plus polynomial dictionary/normalization overhead. A conservative total bound is polynomial in L (for example O(L^7) with elementary arrays and pairwise duplicate removal); no linear-time bound is asserted for this implementation. Saved formulas and the shared strategy circuits have polynomial bit length. The n=0 case evaluates a constant CNF directly. This is the classical tractable quantified-2SAT regime; known stronger algorithms are not needed for correctness of the elimination proof.

General quantified Boolean formulas, including their PSPACE-hard matrices, are outside this width-preserving argument: eliminating a variable from wider clauses can create longer clauses and an exponential number of distinct residual constraints. The proof gives no general polynomial-time PSPACE simulation.
