# An infinite literature counterexample family for preservation of non-word-representability

**Claim type: Literature report.** The prompt's universal implication is **false in the literature**. For each odd \(m\ge5\), let \(G_m=\mu(C_m)\), the Mycielski graph of the odd cycle. Then
\[
 \neg\mathrm{WR}(G_m),\qquad \mathrm{WR}(L(G_m)).
\]
The two substantive inputs are credited theorems of Kitaev–Pyatkin and Mozhui–Dwary–Krishna. We give an explicit construction, explain its exact relevance, and independently check the latter authors' orientation on a substantial finite range. No new priority for the disproof is claimed.

## The explicit family and the two theorem inputs

For odd \(m\ge5\), use original vertices \(v_1,\ldots,v_m\), independent twin vertices \(u_1,\ldots,u_m\), and a vertex \(w\). Indices on the cycle are modulo \(m\). Its edges are
\[
 v_iv_{i+1},\qquad v_iu_{i-1},\quad v_iu_{i+1},\qquad wu_i
 \quad(1\le i\le m).
\]
This is a finite simple graph with \(2m+1\) vertices and \(4m\) edges. Original vertices have degree four, twins degree three and \(w\) degree \(m\).

Kitaev–Pyatkin, *A note on Hameed's conjecture on the semi-transitivity of Mycielski graphs*, proves that \(\mu(H)\) is semi-transitively orientable if and only if \(H\) is bipartite. Since \(C_m\) is not bipartite, \(G_m\) is not semi-transitively orientable. By the established equivalence between word representability and semi-transitive orientability, it is not word-representable.

Mozhui–Dwary–Krishna, arXiv2509.03339v1, **Theorem3**, proves \(L(\mu(C_{2n+1}))\) word-representable for every \(n\ge2\). This supplies the opposite conclusion for precisely the same roots. The actual paper labels its main result Theorem3, even though the prompt's source description calls it Theorem3.1.

At \(m=5\), this already gives an eleven-vertex counterexample root and a twenty-vertex word-representable line graph. The family is unbounded, and its failure of preservation is not a consequence of merely counting chromatic numbers.

## The published orientation as an exact certificate

Here are the source's orientation rules, with an explicit labelled interpretation. A line-graph vertex \(a_{ij}\) represents the edge \(v_i u_j\), while \(a_{0j}\) represents \(wu_j\). These are the \(3m\) vertices of the line graph of the bipartite subgraph formed by all non-cycle edges.

For two such vertices sharing the original endpoint index \(i\), orient from smaller \(j\) to larger \(j\). For two sharing the twin index \(j\), orient from larger \(i\) to smaller \(i\). The index zero is the hub and is not an original-cycle vertex.

Let \(c_i\) represent \(v_iv_{i+1}\) for \(1\le i<m\), and \(c_m\) represent \(v_1v_m\). Orient the line-cycle edges by
\[
 c_{i+1}\to c_i\ (1\le i\le m-2),\qquad
 c_m\to c_1,\qquad c_{m-1}\to c_m.
\]
Every line-graph edge between an \(a\)-vertex and a \(c\)-vertex is directed from \(a\) to \(c\).

The source proves this whole orientation acyclic and shortcut-free in Lemmas3–4, giving Theorem3 through the semi-transitive characterization. Its all-order case analysis is credited external proof; the finite checker below is an independent diagnostic of these exact rules, not a substitute for that proof.

## What the exact checker actually tests

The attached original standard-library verifier reconstructs \(G_m\), takes intersections of its labelled edge endpoint sets to construct the entire line graph, and checks that the orientation gives each line edge exactly one direction. It also verifies the independent counts
\[
 |V(L(G_m))|=4m,\qquad
 |E(L(G_m))|=m\binom42+m\binom32+\binom m2
           =9m+\binom m2.
\]

After a topological sort, it computes strict directed reachability. For an arc \(s\to t\), let
\[
 I_{s,t}=(\{s\}\cup\operatorname{Desc}(s))
          \cap(\{t\}\cup\operatorname{Anc}(t)).
\]
A shortcut exists exactly when some such interval contains vertices \(x,y\) with a directed path \(x\leadsto y\) but no arc \(x\to y\). Indeed the concatenated paths \(s\leadsto x\leadsto y\leadsto t\) form one simple directed path in a DAG; the arc \(s\to t\) shortcuts this path while \(xy\) is missing. Conversely a non-complete path with adjacent endpoints has a missing forward pair of this form. This criterion avoids enumerating only selected paths or incorrectly demanding that mutually incomparable interval vertices be adjacent.

The actual run verifies every odd \(m=5,7,\ldots,101\): **49 cases and2,401,049 arc-interval vertex checks all pass**. The same rules at the excluded \(m=3\) fail with an explicit shortcut, a useful boundary control. Running with Python optimization is rejected before any verification; its exit status was one. Exact output is retained in verification.json.

The program checks the positive finite orientations only. It does not exhaust all orientations of \(G_m\) to certify non-word-representability, construct shortest uniform words, or establish the infinite theorem by sampling.
