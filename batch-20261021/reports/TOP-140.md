# TOP-140 — The one-third frontier, endpoint normalization, and a literal small-set obstruction

**Claim type: Literature report.** The intended research problem seeks arbitrarily small fixed concentration exponents for all sufficiently large integer sets. The earlier report proves a uniform square-root bound. This contribution records the stronger published one-third upper frontier and a subpower lower obstruction, checks their arc conventions, and identifies a finite-size defect in the literal “every $n$” reading. It does not improve the asymptotic exponent below one third.

For a set $A$ of $n$ distinct integers define
\[
M(A)=\inf_{\theta\in\mathbb R/\mathbb Z}\ 
\sup_{\substack{I\text{ half-open circular arc}\\|I|=1/n}}
\#\{a\in A:\theta a\bmod1\in I\}.
\]
Points are counted with multiplicity, just as in the official prompt.

## 1. Published bounds that go beyond the earlier second-moment estimate

Konyagin, Ruzsa and Schlag [1] prove an upper bound of order $n^{1/3+\varepsilon}$ for concentration, for each fixed $\varepsilon>0$. Their Theorem 6.1 supplies integer sets with concentration exceeding
\[
\exp\!\left(c\frac{\log n}{(\log\log n)^2}\right)
\tag{1}
\]
for an absolute $c>0$ and all sufficiently large $n$. These are credited theorems, not arguments reproved here. The primary publisher abstract explicitly records the upper/lower comparison; the author-hosted version's indexed Theorem 6.1 was checked for the lower bound.

Thus for every fixed $c_0>1/3$, the desired bound $M(A)\le n^{c_0}$ holds for every $n$-element set when $n$ is sufficiently large depending on $c_0$. Choose $\varepsilon<c_0-1/3$ and absorb the theorem's fixed prefactor into $n^{c_0-1/3-\varepsilon}$. Green's maintained Problem 86 [2] independently states precisely this known exponent range.

The lower theorem is also substantial: no universal constant, or fixed power of $\log n$, can bound $M(A)$ for all sets. Indeed
\[
\frac{\log n}{(\log\log n)^2}\gg\log\log n.
\]
However (1) is subpower: for every fixed $c_0>0$,
\[
\exp\!\left(c\frac{\log n}{(\log\log n)^2}\right)=o(n^{c_0}).
\]
It is therefore compatible with an affirmative answer to the intended arbitrary-positive-exponent question. A lower bound tending to infinity is not a counterexample to that question.

## 2. Check the actual circle convention before importing either bound

The author-hosted source defines its concentration using the maximum number of labelled images with
\[
\|\theta a-x\|_{\mathbb R/\mathbb Z}<1/n.
\tag{2}
\]
This is an open ball of radius $1/n$, whereas the prompt uses half-open arcs of length $1/n$. We retain the displayed formula rather than relying on an informal use of “interval size”.

Let $K(A)$ be the infimum of the source's maximum in (2). For each fixed dilation, any half-open arc of length $1/n$ lies in the open radius-$1/n$ ball about its midpoint, so its occupancy is at most the source maximum. Conversely an open radius-$1/n$ ball is contained in the union of two consecutive half-open arcs of length $1/n$. Each of those arcs has occupancy at most the prompt maximum. Therefore
\[
M(A)\le K(A)\le2M(A).
\tag{3}
\]
The comparison is pointwise in the same dilation before taking infima; it does not choose two different dilations. Boundary images cause no exception to either containment.

Consequently the upper bound transfers directly and the lower bound loses at most a factor two. For sufficiently large $n$, that factor can be absorbed by decreasing the positive constant $c$ in (1). This verifies that both quoted exponent scales address the literal arc convention and multiplicities.

## 3. A precise warning about “for every $n$”

The exact statement with no sufficiently-large qualification is false for some small sizes. Take
\[
A=\{0,1,3\},\qquad n=3.
\]
For every dilation at least one half-open arc of length $1/3$ contains two labelled images.

Here is a proof including collisions and endpoints. If two images coincide, they already lie in one such arc. Otherwise arrange the three points cyclically, with gaps $g_1,g_2,g_3>0$ summing to one. If one gap is strictly below $1/3$, the arc beginning at its first endpoint contains both endpoints, because its right endpoint is excluded only at distance exactly $1/3$. If no arc has two points, all three gaps must therefore be at least $1/3$, hence all equal $1/3$.

Since zero is one of the images, equal gaps would force the set of images to be $\{0,1/3,2/3\}$. In particular $\theta$ would be $1/3$ or $2/3$ modulo one. But then $3\theta$ coincides with zero, a contradiction. This proves $M(A)\ge2$. Taking $\theta=1/4$ gives points $0,1/4,3/4$, for which no length-$1/3$ arc contains all three; hence $M(A)=2$ exactly.

For every $0<c_0<\log2/\log3$, the number $3^{c_0}$ is below two, so this set defeats the unqualified finite-$n$ formulation. Translating $A$ by any integer rotates all images and leaves the obstruction unchanged; the same holds after multiplication by any nonzero integer, since that multiplication can be absorbed into the dilation.

This finite obstruction is not an asymptotic disproof. A precise intended reformulation is: for every $c_0>0$, there is $n_0(c_0)$ such that the assertion holds for all $n\ge n_0(c_0)$ and all $n$-element integer sets. Another conventional version permits a prefactor depending on $c_0$. We keep these reformulations separate from the literal statement.
