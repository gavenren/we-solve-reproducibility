# Baillie–PSW: local synchronization and the fixed-parameter trap

Claim type: Literature report.

The two literal questions are distinct. The first uses the specified strong base-two test and Selfridge's selected strong Lucas test; the second asks only the two weak divisibilities with Fibonacci numbers. The following exact local criterion for squarefree candidates separates their requirements. It supplies a candidate-construction and rejection framework at arbitrary size, not a numerical search or a counterexample.

Let $n=\prod_{p\mid n}p$ be odd and squarefree, let $D=P^2-4Q$, assume $\gcd(n,2QD)=1$, and use the actual Lucas parameters under discussion. For each $p\mid n$, put
\[
 d_p=\operatorname{ord}_p(2),\qquad
 r_p=\min\{m\ge1:U_m(P,Q)\equiv0\pmod p\}.
\]
The rank $r_p$ exists under these coprimality hypotheses. Write
$n-1=2^su$ and $n+1=2^tv$ with $u,v$ odd. Then the strong base-two test passes **if and only if**
\[
 d_p\mid n-1\quad\text{for every }p\mid n,
 \qquad v_2(d_p)\text{ has the same value for all }p\mid n. \tag{1}
\]
Likewise the strong Lucas test passes **if and only if**
\[
 r_p\mid n+1\quad\text{for every }p\mid n,
 \qquad v_2(r_p)\text{ has the same value for all }p\mid n. \tag{2}
\]
The common value is allowed to be zero. Conditions (1) and (2) each require synchronization across all factors, not independent choices of a successful strong-test index at different primes.

Here is a proof of (2). In the split or quadratic-extension field of $\mathbb F_p$, let $\alpha,\beta$ be the two roots of $X^2-PX+Q$. They are distinct and nonzero. Set $\rho=\alpha/\beta$. The identities
\[
 U_m=\frac{\alpha^m-\beta^m}{\alpha-\beta},
 \qquad V_m=\alpha^m+\beta^m
\]
give $U_m=0$ exactly when $\rho^m=1$, and $V_m=0$ exactly when $\rho^m=-1$. Thus $r_p=\operatorname{ord}(\rho)$, and $r_p\mid p-(D/p)$: in the split case $\rho\in\mathbb F_p^\times$, while in the nonsplit case Frobenius interchanges the roots, so $\rho^{p+1}=1$.

If $r_p$ is odd and divides $v$, then $U_v=0$. If $r_p=2^ec$ with $c$ odd, then $\rho^{2^jv}=-1$ holds precisely when $c\mid v$ and $e=j+1$. This uses the unique element of order two in a finite field's multiplicative group. In the strong test, one global choice must work modulo all prime factors: either $U_v=0$ everywhere, giving common $e=0$, or one $V_{2^jv}=0$ everywhere, giving common $e=j+1$. CRT proves both directions of (2). The same argument with the element $2\in\mathbb F_p^\times$ and exponent $n-1$ proves (1).

For a squarefree $n\equiv3$ or $7\pmod{10}$, the Jacobi symbol $(5/n)=-1$. Thus Method A begins with $D=5$, $P=1$, $Q=-1$, and $U_m=F_m$. In this case the second literal question is exactly
\[
 d_p\mid n-1,\qquad r_p\mid n+1\quad(p\mid n), \tag{3}
\]
where $r_p$ is the Fibonacci rank modulo $p$. It omits both synchronization requirements. A solution of (3) would pass the specified BPSW test only if the two common-valuation conditions are also met. Conversely a squarefree BPSW counterexample in these residue classes satisfies (3). This comparison concerns the squarefree regime; no assertion that an unknown counterexample must be squarefree is made. Method A* has the same strong-test outcomes by the primary paper's AppendixA, so changing from A to A* does not remove this distinction.

The coprimality hypothesis is explicit. If the selected $Q$ has a prime common divisor with $n$ while $\gcd(P,n)=1$, the recurrence modulo that prime has $U_m=P^{m-1}$ for $m\ge1$, and $V_m=P^m$ for $m\ge1$; neither strong condition can hold there. Thus successful candidates in the prompt's Method A ($P=1$) do satisfy the needed $Q$ coprimality. The selected Jacobi value also ensures $\gcd(D,n)=1$. These facts justify using the criterion for successful squarefree candidates, rather than assuming away a potential passing branch.

A different phenomenon explains why an apparently impressive infinite family can miss the problem entirely. Fix $P=Q=2$, so $D=-4$. For every odd $n\equiv3\pmod4$, write $n+1=2^tv$ with $v$ odd; then $t\ge2$. In $\mathbb Z[i]$,
\[
 V_{2v}=(1+i)^{2v}+(1-i)^{2v}
 =(2i)^v+(-2i)^v=0.
\]
Also $(-4/n)=-1$. Therefore **every** such $n$ passes this fixed-parameter strong Lucas condition. Baillie–Fiori–Wagstaff's Theorem2 proves there are infinitely many Carmichael numbers $n\equiv3\pmod4$ which are also strong base-two pseudoprimes. The combination with this fixed Lucas test consequently has infinitely many composite passers, with the infinitude supplied by their published-literature theorem, not by the calculation here.

These are not BPSW counterexamples. Selfridge's rule in the prompt selects odd $D$ from $5,-7,9,-11,\ldots$; it never selects $D=-4$, nor $P=Q=2$. The fixed-parameter identity is a rigorous explanation of why preserving the parameter-selection rule is mathematical substance, not a cosmetic implementation choice. Section8 of the primary paper makes this same warning.

The local-order proof gives complete necessary and sufficient squarefree conditions, while the credited infinite-family theorem exhibits the danger of a different test. Repeated prime factors require prime-power ranks and are outside this report's criterion. No composite satisfying either original question is exhibited; no universal primality guarantee, heuristic independence argument or finite search bound is promoted to a resolution.
