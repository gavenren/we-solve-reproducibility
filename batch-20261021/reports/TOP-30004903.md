# A determinant-sensitive linear bound in row general position

Suppose$n\ge2$ and every$n$ rows of the integral$m\times n$ matrix$A$ are linearly independent. If every full-size minor has absolute value at most$\Delta$, then
\[
m\le n+p-1
\]
for every prime$p>\Delta$. In particular this proves the requested form$m\le nf(\Delta)+g(\Delta)$ for all minimally integer-infeasible systems satisfying this extra row-general-position condition, with$f(\Delta)=1$ and$g(\Delta)=p(\Delta)-1$. It even holds for arbitrary right sides and does not need minimal infeasibility.

If$m<n$, the bound is immediate. Otherwise transpose$A$ to an$n\times m$ matrix and reduce its entries modulo$p$. Every$n$-column determinant is a nonzero integer of magnitude at most$\Delta<p$, hence remains nonzero in$\mathbb F_p$. Thus any$n$ columns are independent over that field.

Choose$n-2$ columns and quotient$\mathbb F_p^n$ by their span. These columns are independent, so the quotient is two-dimensional. The remaining$m-n+2$ columns project to nonzero vectors with pairwise different projective directions. A zero projection would make that column dependent on the chosen$n-2$; two proportional projections would make those two columns together with the chosen ones dependent, contradicting the$n$-column property. There are exactly$p+1$ one-dimensional subspaces in$\mathbb F_p^2$: each nonzero vector belongs to a class of$p-1$ nonzero scalar multiples, so the count is$(p^2-1)/(p-1)$. Therefore$m-n+2\le p+1$, proving the bound.

This proof uses the higher minors in an essential way. Entry bounds alone do not ensure that nonzero determinants survive reduction; the earlier exponential sign-row family accordingly evades this bound by possessing large minors. Conversely the hypothesis that every$n$ rows are independent is essential: bounded minors can be zero, and a zero remains zero modulo every prime. The quotient argument then no longer gives different projective directions.

The primary Kriepke–Kyureghyan–Schymura paper studies exactly this generic-minor setting and proves stronger bounds via MDS codes, including$g(\Delta,n)\le\max(n,p)+1$ in its column-count convention. This report supplies the elementary quotient bound directly and transfers it to the prompt's actual number of rows. It does not copy the source's facet factor of two into a matrix with every$n$ rows independent: allowing pairs of opposite parallel facet normals is a different convention, excluded by our stated row condition.

Both earlier full manuscripts were compared. The canonical attempt supplies the determinant-free$2^n$ parity bound; the duplicate alias gives a sharp exponential family with unbounded minors. Neither gives a determinant-sensitive linear bound under row general position. The present result is a verified structured subclass, not a solution when arbitrary zero minors and parallel/dependent rows are permitted.
