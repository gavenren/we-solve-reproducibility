# Uniformity of Bray’s odd-order output and its precise sampling cost

Problem: TOP-30003185  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** For any finite group G and involution t, Bray’s odd-order branch maps uniform accepted inputs exactly uniformly onto C_G(t). Independent trials give iid uniform accepted outputs. Explicit generation and rejection bounds are derived conditional on its acceptance probability p; no O(log n) classical-group bound or efficient order oracle is assumed.

Let a(g)=t g⁻¹t g. If a(g) has odd order m, define
\[
 z(g)=g\,a(g)^{(m-1)/2}.
\]
Write C=C_G(t) and A for the set of such accepted g. The identity t a(g)t=a(g)⁻¹ implies
\[
 z(g)^{-1}tz(g)=a(g)^{-(m-1)/2}(t a(g))a(g)^{(m-1)/2}=t a(g)^m=t.
\]
Thus z(g)∈C, including m=1.

For c∈C one has a(cg)=a(g), so A is invariant under left multiplication by C and z(cg)=cz(g). For any h₁,h₂∈C, multiplication by h₂h₁⁻¹ bijects the input fiber z⁻¹(h₁)∩A onto z⁻¹(h₂)∩A. All output fibers have equal size. They are nonempty because each g∈C belongs to A and has z(g)=g. Therefore a uniform input conditioned on acceptance gives *exactly* the uniform distribution on the entire centralizer, without assuming t is strong or that G is classical. In particular p=|A|/|G| is positive, though it can be small.

Fresh independent G-samples, independently tested, produce iid uniform C outputs after rejection. To verify this without a hidden independence claim, fix any finite accepted-output prefix. Sum over all intervening rejection lengths. Trial independence factors those probabilities into geometric rejection factors and the common conditional uniform output law. Thus random stopping at acceptance does not bias the output. The expected number of G trials for r accepted outputs is r/p.

There is also a general generation bound, distinct from the source’s sharper classical-group question. Let H_i be generated by i independent uniform C elements. Conditional on H_i<C, a new sample lies outside H_i with probability at least1/2; in that event its generated subgroup has at least twice the previous order. Set Z_i=1_(H_i<C)/|H_i|. Then E[Z_(i+1)|H_i]≤(3/4)Z_i: inside samples do not increase it, outside samples at least halve it, and reaching C sets it to zero. Hence
\[
 \Pr(H_r<C)\le |C|(3/4)^r.
\]
Taking r≥(ln|C|+ln(1/δ))/ln(4/3) makes this failure at most δ. This establishes O(log|C|+log(1/δ)) accepted-output sufficiency, not O(log n).

For a fixed number N of independent G trials, the accepted count is Binomial(N,p). If Np≥2r, the elementary multiplicative Chernoff estimate gives probability below r at most exp(−Np/8). It follows that N≥max(2r/p,8ln(1/δ)/p) yields enough accepted outputs except with probability δ. Together with the preceding generation estimate, allocate δ/2 to each failure term for a total error at most δ. Alternatively the expected-time rejection procedure has exactly r/p expected trials and almost-sure termination.

These statements charge a group-order computation separately. If a(g)’s order m is supplied or computed by a specified routine, powering uses O(log m) group multiplications. In an n-dimensional classical matrix group log|G|=O(n²log q), so the generic generation result is vastly weaker than O(log n). An order-finding oracle, constant acceptance probability, strong involution outputs and full-centralizer versus second-derived-subgroup aims cannot be silently interchanged. The literal strong-involution probability/generation analysis remains outside this report.
