# Linear-space point location for column-wise affine layers

Consider the following structured three-dimensional subdivisions. A planar polygonal subdivision$\mathcal B$ is supplied explicitly. Over each base cell$B$, the vertical column is divided by affine height functions
\[
f_{B,1}(x,y)<\cdots<f_{B,k_B}(x,y)
\quad\text{throughout the relative interior of }B.
\]
Together with top/bottom boundaries if the domain is bounded, they define the three-dimensional cells. Different base cells may have different functions and different numbers of layers. The resulting full face-to-face complex and its incidences are supplied; the displayed column representation is an additional promised description of size$O(n)$, where$n$ is the literal total boundary complexity.

For this entire class, point location has$O(n)$ storage and$O(\log n)$ worst-case query time in the real-arithmetic/pointer model. This includes sloping affine interfaces and a nontrivial planar base subdivision, beyond the earlier attempt's single global stack of horizontal slabs.

Build a planar point-location structure on$\mathcal B$ using Kirkpatrick's theorem: linear space and logarithmic query time. Store the affine functions of each$B$ in their promised vertical order, as a balanced binary search tree with cell identifiers in the gaps. There are$O(|\mathcal B|+\sum_B k_B)=O(n)$ records. For$query$q=(x,y,z)$, first locate$(x,y)$ in the base, then compare$z$ to the middle affine height at$(x,y)$ and descend through that one base cell's height tree. The order promise makes these comparisons a valid binary search, using$O(\log(k_B+1))$ tests. Their sum is$O(\log n)$.

The order cannot change in a base interior: if two distinct affine functions reversed order, continuity on a segment within a convex base cell would give an interior intersection, contrary to the promised strict ordering. One may triangulate polygonal base cells first and duplicate their height lists; to preserve linear space that refinement must already have total column-list size$O(n)$. It is safer to retain the supplied base cells and use the order promise directly than to conceal a quadratic duplication in a triangulation.

For boundary queries, have the planar structure return any incident base cell and use its closed column. If heights coincide along a base boundary, ordinary lower-bound search among their weakly ordered values returns a gap or an equality position with an incident closed3D cell. Finite top/bottom and exterior flags handle points outside the domain. The prompt permits an incident cell, so a query exactly on a vertical edge need not enumerate all neighbouring columns.

A conservative preprocessing bound is$O(n\log n)$ real operations given the embedded planar subdivision, its adjacency and the promised ordered column lists; the planar theorem's stronger linear bound requires its own stated representation/triangulation prerequisites. No projection of an arbitrary3D complex is computed here. Constructing that projection can itself create quadratic complexity, so this theorem does not silently preprocess general subdivisions into the promised class.

For rational coefficients and query coordinates, all affine sign tests are exact rational arithmetic with polynomial overhead in their full bit length. The geometric space bound counts constant-size real records as the prompt requests, not bounded-length bits for arbitrary reals. The earlier attempt's failed global hierarchy is not repaired for general inputs; the restricted column structure is exactly what makes one planar search and one local search sufficient.
