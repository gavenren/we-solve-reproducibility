**Exact source theorem.** In the checked 15 June 2009 manuscript, Theorem 5.12 states that a planar graph can be canonized in logarithmic space. Theorem 5.11 establishes a logspace isomorphism order. Its nontrivial structure is important for the prompt. The algorithm decomposes a connected graph into biconnected components, refines these into triconnected component trees and invokes a canonical treatment of the 3-connected components. Comparing the component-tree shapes alone is insufficient: the orientation of a separating vertex pair controls whether local isomorphisms extend consistently through the full graph. The source explicitly exhibits this failure and introduces orientation counters. Here is a complete useful consequence with output memory accounted for. Let C be the fixed source transducer on this graph subclass. On valid input G of length at most L, its canonical output has length at most L^c for a fixed c. To compute its jth output symbol, start C again, maintain an O(log L)-bit output-position counter, discard all symbols before j, then return that symbol or an end marker. C's O(log L) work tape plus the counter still uses O(log L). The output tape is one-way and is not read back.

Given G,H, compare their canonical outputs by regenerating symbol j from G and H, storing only the two current symbols and j. If they differ, reject; if both outputs have ended, accept; if just one ends, reject. The loop runs through a polynomial number of positions and every restarted transducer is a fixed halting logspace computation. Its non-output configuration and output-position counter have polynomially many possibilities, so the restart simulation is polynomial time. Thus comparison uses logarithmic workspace and polynomial time, not space proportional to the output lengths. Canonical equality is equivalent to graph isomorphism by the source theorem.

Disconnected graphs are covered by the source's planar-graph theorem. Alternatively, a connected-graph canonization routine can be extended without storing a component list: enumerate candidate least-numbered vertices of components, determine membership using undirected connectivity, compare their regenerated canonical strings and output them in canonical multiset order, with multiplicities. A full implementation of this alternative also needs a logspace connectivity procedure; it is mentioned only to expose the required ingredient, not used as an independent proof of Theorem 5.12.
