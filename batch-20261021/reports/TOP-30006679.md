# Weak pigeonhole formulas separate tree and shared resolution proofs

Problem: TOP-30006679  
Claim type: Literature report  
Author: /root/hundred_algorithms

**Exact scope.** A precisely credited Buss–Pitassi separation on the same explicit pigeonhole family: polynomial-size DAG resolution proofs coexist with tree-like proofs of superpolynomial encoded length. Exact input-size conversion is supplied. This is a lower bound for a specified calculus, not NP!=coNP or a lower bound for every Cook–Reckhow system.

The prompt quantifies over the possible choice of proof system. A useful rigorously established partial frontier is a strong separation between two ways of organizing the very same resolution rule. The following results are due to Buss and Pitassi, *Resolution and the Weak Pigeonhole Principle*, exact primary PDF Theorems3 and4. Their proofs are credited, not independently reproved here.

For m>n, use variables P_{i,j}, i in[m], j in[n]. The unsatisfiable CNF F_{m,n} has pigeon clauses
\[
 P_{i,1}\vee\cdots\vee P_{i,n}\quad(i\in[m])
\]
and collision clauses neg P_{i,j} vee neg P_{i',j} for i<i' and j in[n]. No functionality clauses are needed. If an assignment satisfied the CNF, select for each pigeon a hole where its variable is true. A collision clause prevents two selected pigeons using the same hole, giving an injection [m]->[n], impossible. This proves the semantic unsatisfiability directly.

There are mn variables, m+binomial(m,2)n clauses, and mn+2binomial(m,2)n literal occurrences. With binary variable identifiers, the explicit formula length L is Theta(m^2 n log(mn+2)) for m>=2, under an ordinary delimiter encoding. In particular m is not a short binary parameter standing in for an implicit exponentially long formula. The formula itself is the input.

A resolution refutation is a sequence/DAG of clauses ending in the empty clause, using the sound inference from A vee x and B vee neg x to A vee B. In a tree-like refutation a derived occurrence is used at most once; repeated use requires repeated derivations. This difference concerns sharing, not soundness or the Boolean meaning of the formula.

**The checked literature theorems.** Buss–Pitassi Theorem3 gives polynomial-size ordinary resolution refutations once m>=2^{sqrt(n log n)}, with a fixed universal exponent in the displayed threshold regime. Theorem4 says that for every m>n a tree-like refutation requires at least2^n steps. The paper also establishes a monotone normal form for the pigeonhole principle in Theorem1; it is not claimed to be a complete proof system for arbitrary tautologies. We use only the stated ordinary/tree-like conclusions, avoiding an unsupported extension of that normal form.

Choose integer m_n=2^{ceil(sqrt(n log_2 n))}, for sufficiently large n. Standard rounding of the threshold changes m by at most a constant factor; alternatively use the paper's rounded threshold convention. Extra pigeons can be ignored in the upper-bound proof. Thus F_{m_n,n} has a DAG resolution refutation of size polynomial in its own formula length L_n, but every tree-like refutation has length at least2^n. Since
\[
 \log_2 L_n=\Theta(\sqrt{n\log n}),\qquad
 \log\log L_n=\Theta(\log n),
\]
we have n=Theta((log L_n)^2/log log L_n). Consequently the tree-like lower bound is
\[
 2^{\Omega((\log L_n)^2/\log\log L_n)},
\]
which dominates every fixed power of L_n. The result is a genuine superpolynomial separation measured in explicit input size; calling2^n exponential in L_n would overstate it. Clause-count proof size and bit length differ by at most a polynomial in the formula size and proof clause width, which is at most mn here. Hence the polynomial/superpolynomial distinction persists under bit encodings.

**Relevance and boundary.** A verifier checks a resolution DAG in polynomial time in its encoded length by verifying each axiom reference and each local resolvent. The shared proof is therefore an ordinary efficiently checkable certificate. A tree-only search can be asymptotically weaker even with exactly the same inference rule. Conversely, this family is easy in a stronger format already inside resolution, so its tree lower bound cannot exclude the existence of some globally polynomially bounded Cook–Reckhow system.
