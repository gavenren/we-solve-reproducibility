# A p-optimal tautology system would yield a complete disjoint NP pair

Problem: TOP-30006880  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** A complete self-contained proof shows that existence of a p-optimal Cook–Reckhow tautology system implies existence of a polynomial-many-one complete disjoint NP pair. The same implication already follows from proof-length optimality. This necessary consequence does not prove that such a system or pair exists.

A disjoint NP pair (A,B) consists of two disjoint NP languages; inputs outside A∪B are unrestricted. A many-one pair reduction h maps A into the first target set and B into the second, with one total polynomial-time map h. This is different from deciding which side an arbitrary input occupies.

Fix a Cook–Reckhow system P, a polynomial-time surjection onto all propositional tautologies. Define its canonical pair
\[
 S_P=\{(\varphi,1^m):\varphi\text{ is satisfiable}\},\qquad
 R_P=\{(\varphi,1^m):\exists\pi,\ |\pi|\le m,\ P(\pi)=\neg\varphi\}.
\]
Use a fixed parenthesized encoding for negation, with polynomial-time parsing. Both languages reject malformed pairs. S_P is in NP by an assignment witness. R_P is in NP by a proof witness of length at most the explicitly supplied unary m. Soundness of P makes the sets disjoint. The unary convention is indispensable: binary m would not give an NP witness bound in this argument.

Assume P p-simulates every Cook–Reckhow system. Let (A,B) be any fixed disjoint NP pair with polynomially bounded witnesses and polynomial-time verifiers V_A,V_B. By the uniform circuit simulation/Cook encoding, construct in polynomial time a Boolean formula φ_x that is satisfiable exactly when x∈A. One can use a circuit-verification tableau with extra variables, so the construction does not expand arbitrary shared circuits into exponential-size formulas. Its length is polynomial in |x|, and the coefficients of that polynomial depend only on the fixed verifier.

Define another proof system Q. On a branch encoding (x,w), if V_B(x,w)=1, output ¬φ_x; otherwise output a fixed tautology τ. On another branch output P(π). This is a total polynomial-time function, because every unbounded witness or malformed string is rejected before evaluation and the fixed verification/encoding procedures are polynomial in total input length. Every first-branch output is a tautology: if x∈B then x∉A, so φ_x is unsatisfiable. The second branch makes Q surjective onto TAUT. Thus Q is a valid competitor.

The assumed translator t_Q runs in polynomial time and satisfies P(t_Q(σ))=Q(σ). If x∈B, some accepted w has polynomial length in |x|; consequently the Q proof σ=(x,w) and its translated P proof both have lengths bounded by a fixed polynomial p(|x|). Choose a computable integer polynomial m(n) dominating this bound, including all short inputs. The map
\[
 h(x)=(\varphi_x,1^{m(|x|)})
\]
is a deterministic polynomial-time pair reduction: x∈A makes φ_x satisfiable, so h(x)∈S_P; x∈B guarantees a P proof of ¬φ_x of length at most m, so h(x)∈R_P.

The reduction never finds w or the translated proof. It needs only the uniform existential length bound. Its polynomial m can depend on the fixed pair and translator, as allowed for a reduction from that pair. Thus the argument uses only the weaker assumption that P simulates every Q with polynomial proof-length overhead; polynomial-time translation is sufficient but not necessary for this consequence. This is the classical canonical-pair implication associated with Razborov, reconstructed here with all encoding steps exposed.

There is no converse proved here. Completeness of this NP pair does not find proofs or automatically construct translators for a universal system. Nor does a semantic enumeration of sound systems follow from existence of a complete pair. The earlier cofinal-enumeration discussion remains a separate sufficient route to p-optimality; the present result is a necessary structural consequence and possible obstruction.
