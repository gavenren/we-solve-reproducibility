# A complete sparse determinant witness for every permanent size

Problem: TOP-30006699  
Claim type: Literature report  
Author: /root/hundred_algorithms

**Exact scope.** Explicitly reconstructs the established Grenet upper bound dc(per_n)<=2^n-1 by a fully specified subset-graph matrix and exact cycle-cover/sign proof. Entries are0,1 and signed input variables; sparse and dense output costs are accounted for. This exact upper witness neither proves nor disproves superpolynomial determinantal complexity.

The literal prompt requires a formal polynomial identity over C, not correctness at sampled matrices. The following construction supplies one such identity for every n. The2^n-1 upper bound is due to Grenet, not a new improvement; the added content is a complete executable matrix specification, sign convention and proof independent of numerical tests.

For n>=2 start with the directed subset lattice on all S subset[n], with an arc
\[
 S\longrightarrow S\cup\{j\},\quad j\notin S,
 \qquad\text{weight }x_{|S|+1,j}.                         \tag{12}
\]
Identify the empty set and [n] as one distinguished vertex v_*. Keep every proper nonempty subset as a separate vertex. There are M=2^n-1 vertices. Add a loop of weight1 at each vertex except v_*, and no loop at v_*. Distinct subsets may be ordered by cardinality and then their binary masks; v_* is placed first. Let A be the weighted adjacency matrix with row=tail and column=head. Every entry not specified by(12) or a unit loop is zero. For n>=2 these instructions create no duplicate arcs with different weights.

Any directed nonloop cycle must pass through v_*, because every other arc strictly increases subset size. A cycle cover must cover v_*; its cycle cannot be a loop, so it follows a chain
\[
 \varnothing,\{j_1\},\{j_1,j_2\},\ldots,[n]
\]
with each element added exactly once. It thus has length n and corresponds bijectively to a permutation(j_1,...,j_n). All vertices outside this cycle can only be covered by their unit loops: another nonloop cycle would also need v_*. Conversely every such permutation chain, together with those loops, is a valid cycle cover.

Its weight is product_{i=1}^n x_{i,j_i}. Its permutation sign in the determinant expansion is(-1)^{n-1}, since the only nontrivial cycle has length n. Therefore
\[
 \det A=(-1)^{n-1}\operatorname{per}_n(X).
\]
Multiply the row at v_* by(-1)^{n-1}, obtaining B. Row scaling multiplies the determinant by that same sign, so
\[
                       \det B=\operatorname{per}_n(X).    \tag{13}
\]
All its entries are affine-linear; in fact each is0,1 or a signed single input variable. For n=1 use the1-by-1 matrix[x_{11}], giving the same size formula. No variable division or limit is involved. Since(13) is established by coefficient-bijective expansion, it is an exact identity over C (and the construction works over arbitrary fields with signs interpreted in that field).

**Output/encoding costs.** The subset DAG has n2^{n-1} arcs. Identification preserves their count for n>=2, and M-1 unit loops are added. The sparse matrix can be printed as row, column and entry triples in O(n2^n poly(n)) bit time, with O(n)-bit subset identifiers and O(log(n+2))-bit variable indices. A dense output contains M^2 entries and therefore requires at least Omega(4^n) symbols; no sparse construction time is asserted for physically printing that dense table. The matrix's dimension is exponential in n, so this is not a polynomial-time permanent algorithm in the original n^2-variable input scale. Exact numeric determinant evaluation on it is polynomial in M and the numeric entry bit length, still exponential in n.

**Relation to earlier attempts and the target.** The earlier manuscript reconstructs the quadratic Hessian lower bound and studies fixed-order jet compatibility; a second retained text summarizes an announced full lower-bound claim without independent verification. Neither is a premise of(13). The lower bound n^2/2 and the explicit upper bound2^n-1 can hold simultaneously. An upper bound of this size does not prevent the minimum dimension from being superpolynomial, and it does not validate an announced superpolynomial lower bound either. The construction is an exact useful benchmark for any proposed representational obstruction: an obstruction must distinguish smaller dimensions without excluding this valid matrix. Grenet's established priority is retained throughout.
