# Oddness four and a cut certificate for cubic5-flows

**Claim type: Literature report.** Mazzuoccolo and Steffen prove that every cyclically6-edge-connected cubic graph with oddness at most4 has a nowhere-zero5-flow [1, Theorem1.2]. We retain that full hypothesis and credit the proof. We also derive a precise partition certificate for5-flows on loopless cubic graphs, explaining the orientation requirement rather than silently assuming a prescribed outdegree sequence can be realized.

A2-factor is a spanning2-regular subgraph. The oddness \(\omega(G)\) of a bridgeless cubic graph is the minimum number of odd circuits among its2-factors. Cyclic6-edge-connectivity means every edge cut separating two subgraphs each containing a cycle has size at least6; it is not the impossible demand that all ordinary cuts of a cubic graph have size6. The theorem applies when \(\omega\le4\), not to all bridgeless cubic graphs. Its integer flow values are1 through4 after directions are chosen, equivalent to the prompt's signed values with a fixed reference orientation.

For a loopless cubic multigraph \(G\), write \(\delta(X)\) for the edges with exactly one endpoint in \(X\). A partition \(V=B\sqcup W\) certifies a5-flow if and only if
\[
 |B|=|W|,\qquad
 5\,\bigl||X\cap B|-|X\cap W|\bigr|\le3|\delta(X)|
 \quad\text{for every }X\subseteq V.
 \tag{1}
\]
The source's exact external input is Jaeger's balanced-valuation characterization [1, Theorem2.1]: a graph has a nowhere-zero \(k\)-flow if and only if it admits an orientation \(D\) and a balanced valuation
\[
 f(v)=\frac{k}{k-2}(2d_D^+(v)-d_G(v)),
 \qquad
 \left|\sum_{v\in X} f(v)\right|\le|\delta(X)|\quad\forall X.
 \tag{2}
\]
The cubic \(k=5\) specialization is stated explicitly in the source as valuations with values \(\pm5/3\).

For clarity we verify the missing orientation realization in the sufficient direction. Put \(s(v)=1\) on \(B\), \(-1\) on \(W\), and prescribe outdegrees
\[
 a(v)=(3+s(v))/2\in\{1,2\}.
\]
The balance condition gives \(\sum_va(v)=3|V|/2=|E|\). For every \(X\),
\[
 \sum_{v\in X}a(v)-|E(X)|
 =\tfrac12\left(\sum_{v\in X}s(v)+|\delta(X)|\right)\ge0,
\]
because(1) gives \(|\sum_Xs|\le3|\delta(X)|/5\le|\delta(X)|\).

Create a bipartite incidence graph with one node per edge of \(G\) on the left and \(a(v)\) slots at vertex \(v\) on the right; each edge-node is adjacent to every slot at its endpoints. For any edge subset \(F\), let \(X\) be all its endpoints. Its neighboring slot count is \(\sum_{X}a(v)\ge |E(X)|\ge|F|\). Hall's theorem gives a matching covering all edge-nodes. There are exactly \(|E|\) slots, so every slot is used. Orient an edge away from the endpoint of its matched slot. This realizes outdegrees \(a(v)\). Now \(f(v)=5s(v)/3\) satisfies(2) by(1), so Jaeger's theorem supplies the integer5-flow.

Conversely, a nowhere-zero5-flow on a cubic graph gives the \(\pm5/3\) balanced valuation in the stated cubic specialization of(2). Define \(B,W\) by its signs. The cut inequality becomes(1), and applying it to \(X=V\) gives equal part sizes. Thus(1) is exactly a certificate, not merely a necessary cut heuristic.

For a3-edge cut,(1) and \(\sum_Xs\equiv |X|\equiv|\delta(X)|\pmod2\) force \(|\sum_Xs|=1\). For a bridge the same parity would require an odd nonzero imbalance while(1) bounds its magnitude by3/5, impossible. These checks show that the certificate respects two sensitive small-cut boundaries. The all-subsets condition is essential; testing only individual vertices would lose the content.

The earlier contribution covers lexicographic cycle flows, even-subgraph covers and finite-field/integer lifting, not the oddness-four structural theorem or this orientation-complete partition formulation. No claim is made that every bridgeless cubic graph admits such a partition. No program execution or rerun of the source proof is asserted.
