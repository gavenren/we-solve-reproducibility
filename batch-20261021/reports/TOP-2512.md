# A uniform degree-fourteen bound for semiregular subgroup pairs

Claim type: **Partial result**.

Call a permutation subgroup **semiregular** if every nonidentity element fixes no point. We prove the following uniform result:

**Theorem.** Let $n\ge14$, and let $G=S_n$ or $G=A_n$ in its given degree-$n$ action. If $H,K\le G$ are semiregular, then some $x\in G$ satisfies $H\cap K^x=1$.

The subgroups need not be soluble. In particular this proves the prompt's proposed threshold twenty-one for every semiregular pair, simultaneously in both ambient groups. It is an infinite class in every degree, rather than a finite verification. Small-support elements in general soluble subgroups are not covered.

We first record an exact certificate that applies to arbitrary subgroups of any finite group $G$. Let $\mathcal C$ be the set of its conjugacy classes consisting of elements of prime order, and put
\[
 Q(H,K)=\sum_{C\in\mathcal C}
 \frac{|H\cap C|\,|K\cap C|}{|C|}. \tag{1}
\]
If $Q(H,K)<1$, there is a conjugator with trivial intersection. Indeed choose $x$ uniformly in $G$. For any fixed $h\in C$, the probability that $h\in K^x$ is $|K\cap C|/|C|$, by uniformity of a random conjugate. Thus (1) is the expected number of prime-order elements in $H\cap K^x$. Every nontrivial finite group contains such an element: take a suitable power of any nonidentity element. If every intersection were nontrivial, that expectation would be at least one. This proves the certificate, with the conjugator drawn from the actual ambient group.

Semiregularity gives two useful facts. First, every $H$-orbit has size $|H|$, since its point stabilizers are trivial. Hence $|H|\le n$, and likewise $|K|\le n$. Second, a prime-order nonidentity element in either subgroup has cycle type $p^t$, with $pt=n$. There are no fixed points. Its symmetric-group conjugacy class has size
\[
\frac{n!}{p^t t!}.
\]
Since $t=n/p\le n/2$ and $t!\le t^t$,
\[
p^t t!\le (pt)^t=n^t\le n^{n/2}. \tag{2}
\]
An $S_n$-class contained in $A_n$ either stays one class or splits into two classes of equal size: the acting subgroup has index two. Therefore in **both** possible ambient groups every relevant class has size at least
\[
\frac{n!}{2n^{n/2}}. \tag{3}
\]
This factor two avoids assuming that a useful symmetric-group conjugator is even.

All summands are nonnegative. Combining (1)–(3),
\[
 Q(H,K)\le \frac{2n^{n/2}}{n!}
 \sum_{C\in\mathcal C}|H\cap C|\,|K\cap C|
 \le \frac{2n^{n/2}(n-1)^2}{n!}=:r_n. \tag{4}
\]
For the last inequality, the two separate sums count only nonidentity elements and are at most $|H|-1$ and $|K|-1$. A sum of matched products is at most the product of these separate sums.

Here is a complete bound in the degree parameter, not an unchecked asymptotic estimate. At $n=14$,
\[
 2\cdot14^7\cdot13^2=35\,629\,764\,352
 <87\,178\,291\,200=14!,
\]
so $r_{14}<1$. For $n\ge14$,
\[
\frac{r_{n+1}}{r_n}
=\frac{(1+1/n)^{n/2}}{\sqrt{n+1}}
 \left(\frac n{n-1}\right)^2
<\sqrt{\frac3{n+1}}\left(\frac n{n-1}\right)^2<1. \tag{5}
\]
The first strict inequality uses $(1+1/n)^n<e<3$. Both factors in the final expression decrease with $n$; at fourteen its square is
$\frac3{15}(\frac{14}{13})^4<1$, because $14^4=38\,416<5\cdot13^4=142\,805$. Thus (5) holds at every subsequent degree. Equations (4) and (5) imply $Q(H,K)<1$, proving the theorem.

The argument also gives the quantitative statement
\[
\Pr_{x\in G}(H\cap K^x=1)\ge1-r_n>0.
\]
It applies to all regular subgroups as well as semiregular subgroups with several orbits. For example, any two regular embeddings of groups of order $n$ into $S_n$ satisfy the conclusion when $n\ge14$, and the same is true inside $A_n$ whenever those embeddings have even image.

The prime-order class-sum method is a standard fixed-point-ratio argument; no priority is claimed for that method. The contribution supplies a fully explicit sufficient condition, checks the alternating-group parity issue, and obtains the uniform degree-fourteen subclass theorem. It does not prove the assertion for arbitrary soluble subgroups, which may have large point stabilizers and many elements moving very few points.
