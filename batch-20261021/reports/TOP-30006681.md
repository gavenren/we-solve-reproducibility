# Quantum queries do not enlarge PP: an explicit signed-count simulation

Problem: TOP-30006681  
Claim type: Literature report  
Author: /root/hundred_algorithms

**Exact scope.** The established Fortnow–Rogers lowness theorem PP^BQP=PP, explained through exact fixed-gate path counts, common denominators, adaptive oracle transcripts and exponential error control. This is a counting-class upper bound and decides neither NP subset BQP nor BQP subset NP.

A PP computation accepts when strictly more than half its equally likely polynomially many random bits lead to acceptance. The gap may be as small as2^{-T} for a machine using T bits, so ordinary inverse-polynomial approximation is insufficient. Nevertheless a PP machine gains no power from a fixed BQP language as an oracle. This is Fortnow–Rogers Corollary3.4, using their Theorems3.1 and3.3; the following direct signed-count explanation keeps the errors and adaptivity visible.

Use the prompt's fixed Toffoli/Hadamard/phase-i circuit basis, retaining discarded wires until the end. With h Hadamards, each path has a polynomial-time computable final string and Gaussian-integer phase, and acceptance is
\[
 p_y=G(y)/2^{h},
\]
where G is a sum over pairs of paths of values in{-1,0,1}. Two paths contribute only when their entire final strings agree and the output accepts; take the real part of their relative phase. The h-dependent denominator follows by squaring2^{-h/2}, not by dividing by the number2^{2h} of path pairs. This standard exact path expression already appears in the earlier attempt. Here we use the extra algebraic structure it supplies: G is a GapP function, a difference of two numbers of polynomially recognizable nondeterministic branches. Polynomial sums, differences, products, and sums over exponentially many polynomial-bit indices preserve GapP. These closure operations are realized by choosing indices/branches and multiplying their signs; zero summands are implemented by cancelling accepting/rejecting branches.

Fix a PP oracle machine M, polynomial time bound and at most q queries to a BQP language A. Pad its coin count to a known T on every branch. Its exact integer acceptance-minus-rejection count g is at least1 on yes inputs and at most0 on no inputs; ties are handled explicitly below. Amplify A's error uniformly to epsilon<2^{-T-4}/max(1,q); polynomially many repetitions suffice since T and log q are polynomial in input length. All possible queried strings have polynomial length. The amplified acceptance probability for a query y has a GapP numerator g(y) and a denominator that can be made one common D=2^H for this simulation length: increase each numerator by the integer power2^{H-h(y)}. A polynomial upper bound H on Hadamard counts suffices. This is exact denominator alignment, not approximation of gate constants.

**A single GapP numerator for adaptive transcripts.** Enumerate M's random string r and an answer transcript b in{0,1}^q, padding with ignored queries after it halts. Simulate M on those answers to compute its actual query strings y_j(r,b_{<j}) and final sign sigma(r,b) in{-1,1}. Attach weight
\[
 W(r,b)=\prod_{j=1}^q
 \begin{cases}g(y_j),&b_j=1,\\ D-g(y_j),&b_j=0.\end{cases}
\]
The integer S=sum_{r,b} sigma(r,b)W(r,b) is GapP by the stated closure properties. Dividing by2^T D^q gives exactly the expected acceptance sign of a computation which answers each adaptive query by an independent run of the amplified quantum decision procedure. Although the queried strings depend on earlier answers, the product weights are the correct sequential conditional probabilities. No assumption of nonadaptive queries is made.

Couple these simulated answers to the exact oracle answers. Conditional on any past transcript, a next query is a fixed string and its error is at most epsilon; hence the probability of any wrong answer is at most q epsilon. The expected sign therefore differs from M's exact-oracle expected sign by at most2q epsilon<2^{-T-3}. Multiplying by2^T, the quantity S/D^q therefore approximates the integer g to error less than1/8. The GapP integer 2S-D^q has the same sign as 2g-1: the latter is at least1 on yes inputs and at most-1 on no inputs, and the scaled approximation error is below1/4. This treats an exact tie g=0 as rejection. A PP machine decides that GapP sign, which proves PP^A subset PP. The reverse inclusion ignores the oracle. Thus PP^BQP=PP.

The full Fortnow–Rogers result uses the broader class AWPP; no equality BQP=AWPP is asserted here. The simulation is an unbounded-error counting algorithm: its acceptance bias can be exponentially small. It is not a BPP simulation, an NP witness for G's value, or a deterministic way to evaluate all interference. Thus it adds a meaningful containment/lowness frontier while preserving both unresolved directions in the prompt. All circuit/coin/transcript indices have polynomial length; the exponentially many terms are represented by nondeterministic counting, not charged as a deterministic polynomial-time loop.
