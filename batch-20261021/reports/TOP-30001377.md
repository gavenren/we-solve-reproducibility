# Logarithmic conjunction growth for arbitrary balanced functions on independent blocks

Problem: TOP-30001377  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** Under the source’s exact functional ams(f)=E_x max_j sens(f_j,x), prove ams(g)≤(⌈log₂(4n)⌉+2)ams(f) for n Boolean functions that are each constant or balanced, with the nonconstant functions depending on pairwise disjoint coordinate blocks, and any n subset conjunctions. Internal block functions are arbitrary and have no pointwise sensitivity bound. Constant padding fits nontrivial block functions into the literal n-functions/n-input-bits regime. The general correlated case remains untreated.

The report defines average maximal sensitivity with the maximum **inside** the uniform-input expectation. Let the input coordinates be partitioned into blocks B₁,…,B_n (unused coordinates are allowed), allow each f_j to be constant, and require every nonconstant f_j to depend only on its own block B_j and satisfy Pr[f_j=1]=1/2. Constant-one functions can be ignored inside a conjunction, and an output containing a constant-zero function is constant zero and can be discarded. Thus write each remaining J_i using only nonconstant balanced functions; the number of outputs remains at most n. Put Z_j(x)=sens(f_j,x), A(x)=max_j Z_j(x), and a=E[A]. The block pairs (f_j,Z_j) are independent, although within a block f_j and Z_j may be arbitrarily correlated. A zero-size active block cannot be balanced. Constants contribute zero sensitivity and may use empty blocks.

We first prove a weighted conditioning lemma which replaces the constant A=1 of the coordinate-function proof. For J a subset of the active balanced functions, let E_J be the event that every f_j with j∈J is one. Then
\[
 \mathbb E[A\,1_{E_J}]\le4\,2^{-|J|}a. \tag{1}
\]
For a real threshold t≥0 write p_j=Pr[Z_j>t] and s=Σ_j p_j. By independence,
Pr[A>t]=1−∏_j(1−p_j)≥1−e^{-s}. Conditioning on E_J preserves independence between the blocks. For j∈J its conditional tail is at most 2p_j, and for j∉J it is still p_j. A union bound therefore gives
Pr[A>t|E_J]≤min(1,2s)≤4(1−e^{-s})≤4Pr[A>t].
For 0≤s≤1 the middle inequality follows from 1−e^{-s}≥s/2; for s≥1 it follows from 1−e^{-1}>1/2. Integrating the nonnegative tail proves E[A|E_J]≤4a. Since Pr[E_J]=2^{-|J|}, (1) follows. The same proof works for J empty; no division by a is needed, including a=0.

After the constant simplifications just described, g_i=∧_{j∈J_i}f_j. If g_i(x)=0, every flip changing g_i must change a selected false f_j, so sens(g_i,x)≤A(x). If g_i(x)=1, disjointness of the coordinate blocks gives sens(g_i,x)=Σ_{j∈J_i}Z_j(x)≤|J_i|A(x). Empty conjunctions have sensitivity zero. Set K(x)=max({|J_i|:E_{J_i} holds}∪{0}). Pointwise,
\[
 \max_i\mathrm{sens}(g_i,x)\le A(x)(1+K(x)).
\]
Using (1), for each integer k≥1,
\[
 E[A1_{K\ge k}]
 \le\min\{a,\sum_{i:|J_i|\ge k}E[A1_{E_{J_i}}]\}
 \le a\min\{1,4n2^{-k}\}.
\]
Let q=⌈log₂(4n)⌉ for n≥1. Summing the finite tail of K and bounding it by the infinite geometric tail gives
\[
 \mathrm{ams}(g)\le a\left(1+\sum_{k\ge1}\min(1,4n2^{-k})\right)
 \le a(1+q+4n2^{-q})\le(q+2)a.
\]
For n=0 both maxima can be defined as zero; the displayed logarithmic formula is only asserted for n≥1. In particular a family satisfying a=O((log(n+2))^d) has ams(g)=O((log(n+2))^{d+1}) under these restrictions.

The conditioning lemma is essential: multiplying the rare all-one probability by a pointwise maximum-sensitivity bound would not prove the stated result when individual sensitivities have large spikes. No bound on block dimensions or on their maximum sensitivities is imposed here. The earlier coordinate argument is recovered when every block has one coordinate. To stay within the report’s literal n functions on n input bits while using larger blocks, take any m≤n disjoint balanced block functions on those bits and append n−m constant-one functions. The maximum input sensitivity is unchanged; arbitrary conjunctions are still covered. For example disjoint three-bit majority functions plus constant-one padding give non-coordinate balanced functions whose sensitivity varies internally. Thus this restriction is not forced back to n singleton blocks by the source’s shared n notation. The proof does not transfer independence from marginal balance alone: overlapping blocks can correlate both the outputs and the sensitivity variables. That is the precise missing hypothesis in the general source question. No historical novelty or solution for arbitrary functions is asserted.
