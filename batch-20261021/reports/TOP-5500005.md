# A sparse exact candidate graph for parallel-line inputs

Suppose the input points lie on$r$ distinct supplied parallel lines in fixed-dimensional Euclidean space, with their line memberships given. An exact Euclidean MST can be computed in$O(rn\log n)$ real-arithmetic time and$O(rn)$ space. Thus the near-linear target holds for every fixed number of parallel lines, without requiring the points to be planar or equally spaced. This is a restricted input theorem, not an algorithm for arbitrary point sets.

Choose a common direction vector$v$ and use the scalar coordinate$t(p)=p\cdot v$. Along one line connect consecutive points. For each pair of occupied lines, merge their points in increasing$t$ order. Group equal$t$ values; each group has at most two points. Add all edges within a group and all edges between consecutive groups. Across all line pairs there are$O(rn)$ candidates: a point participates in$r-1$ merged lists, and each list contributes only a constant number of edges per point. Sorting each line once and merging gives$O(n\log n+rn)$ construction time.

Every edge of every Euclidean MST belongs to this graph. For points on the same line, an edge skipping an intermediate point$z$ has both$|p-z|,|q-z|<|p-q|$. For points on different lines, a missing candidate edge has an intervening nonempty projection group. Choose$z$ in that group. It lies on the line of one endpoint, say$p$, and strictly between the two endpoint projections. Orthogonal decomposition gives
\[
 |p-z|<|p-q|,\qquad
 |q-z|^2=D^2+(t(q)-t(z))^2/\|v\|^2
       <D^2+(t(q)-t(p))^2/\|v\|^2=|p-q|^2,
\]
where$D>0$ is the distance between the two lines. A tree containing$pq$ splits into two components when that edge is removed. Whichever component contains$z$, one of$pz,qz$ reconnects them with strictly smaller weight, contradicting minimality. Equal projections create no hidden exception: the candidate graph explicitly includes their whole group and its neighboring groups. If$r=1$, the consecutive chain already is the answer.

Run Kruskal on the candidate graph using squared distances for comparisons. Squaring preserves the ordering of nonnegative Euclidean lengths, so Kruskal's cut argument minimizes the original sum of lengths; it does not minimize a different squared-length objective. Existence of a complete-graph MST contained in the candidates also guarantees connectivity. Sorting$O(rn)$ edges costs$O(rn\log n)$ since$r\le n$.

These are the unit-cost real operations requested in the prompt. For rational input and rational supplied$v$ of total encoded length$L$, all projection and squared-distance comparisons can instead be performed exactly with polynomial-in$L$ arithmetic overhead; no constant bit cost or comparison of sums of square roots is assumed. The line-membership promise is part of this subclass; recognizing arbitrary best-fit lines is not included.
