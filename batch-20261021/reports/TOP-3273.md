# Connected planar digraphs with half-order acyclic sets

**Claim type: Literature report.** For every integer $f\ge1$, the construction below is a strongly connected planar oriented graph $D_f$ on $2f+1$ vertices with maximum induced acyclic-set size exactly $f+1$. Thus the literal $3n/5$ assertion fails at every odd $n\ge7$, even under strong connectivity. This specializes the known Knauer–Valicov–Wenger construction; no new disproof priority is claimed.

TOP-3273-A1 already verifies the seven-vertex example and disjoint unions with ratio $4/7$. Here connectivity is retained and the ratio tends to $1/2$. The separate conjectured half-order lower bound is not proved.

## Complete arc data

Use vertices $z,x_0,y_0,\ldots,x_{f-1},y_{f-1}$. Begin with $x_0\to y_0\to z\to x_0$. For each $1\le i<f$, add precisely
\[
x_{i-1}\to x_i,\quad y_{i-1}\to x_i,\quad x_i\to y_i,\quad
y_i\to x_{i-1},\quad y_i\to y_{i-1}.
\]
There are $5f-2$ arcs and no loops or opposite pairs. These are all the arcs; acyclicity tests must retain every arc between selected vertices.

## Planarity and connectivity

Maintain a plane triangulated supergraph with a triangular face incident with the current edge $x_{i-1}y_{i-1}$. Initially use the bounded face $x_0y_0z$. If the current face is $uvw$, insert $x_i$ into it and join it to $u,v,w$. Insert $y_i$ into face $uvx_i$ and join it to its boundary. The five required new edges are present; $x_iw$ is only an extra edge of the supergraph. Face $ux_iy_i$ permits the next step. All insertions occur inside faces, proving planarity of the supergraph and the specified subgraph.

The original triangle is strongly connected. Old vertices reach $x_i$ through $x_{i-1}\to x_i$, while $x_i$ reaches the old graph through $x_i\to y_i\to x_{i-1}$. The vertex $y_i$ is reached through $x_i$ and reaches $x_{i-1}$. Induction proves strong connectivity. Digirth is three, since the initial directed triangle remains.

## Exact feedback vertex number

Let $S$ meet every directed cycle. Write
\[
s_i=|S\cap\{x_i,y_i\}|\in\{0,1,2\},\qquad c=\mathbf1_{\{z\in S\}}.
\]
The initial triangle forces $s_0+c\ge1$. The two triangles
\[
x_{i-1}\to x_i\to y_i\to x_{i-1},\qquad
y_{i-1}\to x_i\to y_i\to y_{i-1}
\]
force $s_i=0\Rightarrow s_{i-1}=2$ for $i>0$.

Charge each zero layer $i>0$ to its predecessor, which has value two. Different zero layers have different predecessors. If layer zero has value zero, charge it to $z$, which must then be deleted. If $a_j$ counts layers of value $j$, this injective charging proves $a_0\le a_2+c$. Therefore
\[
|S|=a_1+2a_2+c=f+a_2-a_0+c\ge f.
\]
Only necessary cycle-hitting conditions were used; additional directed cycles cannot invalidate this lower bound.

Conversely, delete all $x_i$. The entire remaining induced graph is the directed path
\[
y_{f-1}\to y_{f-2}\to\cdots\to y_0\to z.
\]
It has $f+1$ vertices and is acyclic. Thus the feedback vertex number is exactly $f$, and the maximum induced acyclic-set size is exactly $f+1$.

For $f\ge3$,
\[
5(f+1)<3(2f+1),
\]
so the required $3n/5$ bound fails independently of integer rounding. Moreover
\[
\frac{\alpha_{\rm ac}(D_f)}{|V(D_f)|}=\frac{f+1}{2f+1}\longrightarrow\frac12.
\]
No universal fraction strictly greater than $1/2$ can hold, even for strongly connected planar oriented graphs. This upper obstruction supplies no universal lower bound.

This is an established obstruction family presented with full certificates, not a new resolution.
