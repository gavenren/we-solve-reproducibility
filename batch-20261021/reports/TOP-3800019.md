# Exact polygon counting and sampling with few interior points

Let$k$ be the number of points strictly inside the convex hull and$h=n-k\ge3$ the number on its boundary. General position ensures that all boundary points are hull vertices. We give an exact algorithm examining
\[
B=k!\binom{h+k-1}{k}=k!\binom{n-1}{k}
\]
candidate polygons. With rational coordinates of total binary input length$L$, its time is$B\,\mathrm{poly}(n,L)$ and its working space polynomial in$n,L$. It counts undirected polygonizations and samples them exactly uniformly. Thus it solves both questions for each fixed$k$; it is an XP bound, not a fixed-parameter or unrestricted polynomial-time result.

First compute the convex hull and label its vertices$v_1,\ldots,v_h$ counterclockwise, with$v_1$ chosen deterministically. In every simple polygonization their cyclic order is this hull order or its reverse. A useful proof uses the Jordan separation property inside the convex hull disk: two disjoint polygon arcs joining pairs of alternating hull-boundary points cannot exist, since the first arc and one boundary arc separate the endpoints of the other. If the hull order of a Hamiltonian Jordan cycle were not the boundary order, some two disjoint arcs along that cycle would have alternating boundary endpoints, a contradiction. Orienting the cycle counterclockwise on its hull vertices and starting at$v_1$ therefore gives each undirected polygonization a unique representative.

Enumerate a permutation of the$k$ interior points and a weak composition of$k$ into$h$ parts. Assign successive blocks of that permutation to the$h$ gaps$v_i\to v_{i+1}$, with$v_{h+1}=v_1$. The number of compositions is$\binom{k+h-1}{h-1}$. Every possible canonical polygonization appears exactly once: read its interior points in cycle order to recover the permutation, and count them between successive hull vertices to recover the composition. Conversely each pair specifies one candidate ordering, although its edges may cross.

Test all pairs of nonadjacent edges for intersection. With no three input points collinear, these pairs have distinct endpoints and can intersect only in a proper crossing. The signs of four orientation determinants decide each test exactly. Adjacent edges meet only at their shared endpoint, because collinearity is excluded. Therefore a candidate passes precisely when it is a simple closed polygon. This costs$O(n^2)$ determinant/sign tests per candidate. Rational additions and multiplications in a fixed-size orientation determinant have polynomial bit cost in$L$; no real-RAM unit-cost arithmetic is assumed in the bit statement.

Increment an integer counter on each success. It never exceeds$B$ and thus has at most$O(n\log(n+1))$ bits, since$B$ is bounded by the number of all labelled orderings. Enumeration may be streamed, so only the current permutation, composition, polygon and counter are needed. This proves exact counting with the stated space bound.

For sampling, first determine$N>0$ by the same pass. Positivity follows, for example, by the standard angular-order construction about an interior point chosen so that no point lies on a coincident ray: consecutive radial sectors give a simple polygon. Draw a uniform integer$J$ in$\{1,\ldots,N\}$ using unbiased random bits. Specifically let$b=\lceil\log_2N\rceil$, draw$b$ bits, and reject if the resulting integer is at least$N$; acceptance probability exceeds one half except the trivial$N=1$ case, handled directly. Stream a second pass and return the$J$th passing polygon. The unique enumeration proves exact probability$1/N$ for every undirected polygon. Expected random-bit cost is$O(\log(N+1))$, and expected total time is the claimed bound.

The hull-order reduction is the geometric ingredient saving the unrestricted factorial search when$k$ is fixed; it is not uniform sampling from a biased geometric heuristic. The general-position and complete rational-coordinate encoding are essential to the stated tests and bit accounting. The source's extremal questions, other noncrossing graph families, and polynomial counting for unbounded$k$ remain untreated.
