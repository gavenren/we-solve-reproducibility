# A deterministic unweighted hardness range below the Dinur–Safra threshold

**Exact scope.** Credit and specialize the Dinur–Safra theorem: deterministic polynomial-time NP-hardness holds for every fixed approximation factor α<10√5−21 on simple unweighted Vertex Cover, hence for the literal prompt whenever ε>23−10√5. A complete rational weighted-to-unweighted rounding argument preserves the fixed gap with polynomial output length. The full factor-two threshold is not claimed.

The checked published primary paper, Dinur–Safra (Annals 2005), Theorem 1.1, proves hardness for every fixed α<ρ=10√5−21. The stronger assertion for every α<2 in the retained 2026 claim summary is not independently endorsed here. We use the established theorem and reproduce the conversion that matters to the prompt's **simple unweighted, deterministic, explicit** encoding.

The source's weighted independent-set gap, Corollary 2.3, has normalized total vertex weight one and parameters p<p_max=(3−√5)/2. For p>1/3 its yes independent-set weight is at least p−η and its no weight is at most p•+η, where p•=4p³−3p⁴ and η>0 can be any sufficiently small fixed constant. Complements give vertex-cover bounds 1−p+η and 1−p•−η. As p tends to p_max from below,
\[
 \frac{1-p^\bullet}{1-p}\longrightarrow10\sqrt5-21=\rho.
\]
For any fixed α<ρ, choose a rational p in (1/3,p_max) with that ratio greater than α, then choose fixed positive rational η,ζ small enough that
\[
 \alpha(1-p+\eta+\zeta)<1-p^\bullet-\eta-\zeta. \tag{1}
\]
These constants depend only on the desired factor and are fixed before the source instance is read. The source's PCP/biased-long-code gap theorem is deep credited input, not independently reproved in this report.

Here is the full bit-safe conversion for any explicitly given loopless weighted graph with nonnegative rational vertex weights w_v summing to one, n≥1 vertices. Choose an integer M≥4n/ζ and replace vertex v by c_v=⌈Mw_v⌉+1 mutually nonadjacent clones. Replace each edge uv by all edges between the two clone classes. The output is a simple unweighted graph on N'=Σ c_v vertices, where M+n≤N'≤M+2n. All classes are nonempty, even for zero-weight vertices. Put w'_v=c_v/N'. Since c_v=Mw_v+e_v with 1≤e_v<2 (or at the endpoints ≤2),
\[
 \sum_v|w'_v-w_v|
 \le\frac{\sum_v e_v+(\sum_v e_v)\sum_vw_v}{N'}
 \le4n/M.
\]
The chosen M ensures this is at most ζ. Thus every subset's normalized weight changes by at most ζ.

An independent set in the clone graph can be enlarged to contain every clone of each class it meets. The corresponding original vertices form an independent set: if two adjacent original classes were both met, the chosen clones would be adjacent. Conversely an original independent set yields all its clones. Therefore maximum normalized independent-set size in the clone graph is exactly maximum w'-weight of an original independent set, within ζ of the original weighted optimum. Taking complements gives the same additive ζ bound for the minimum normalized cover. This proves both directions without assuming that a partially selected class is an original cover.

There are O(n/ζ) output vertices and O((n/ζ)²) potential output edges. Computing each ceiling uses ordinary rational arithmetic polynomial in the input bit length and log M. A huge common denominator is never expanded into a huge number of clones. For the fixed ζ in (1), the whole explicit output is polynomial and the construction deterministic. Equation (1) now separates the two unweighted cover ranges using any α-approximation: on yes inputs its returned valid cover is below the no lower bound, whereas every valid cover on a no input exceeds that boundary.

Finally α=2−ε<ρ is equivalent to ε>23−10√5≈0.6393. The endpoint α=ρ is not included. This is a significant proved subrange of the literal ε∈(0,1] quantifier, not hardness for every positive improvement over two.
