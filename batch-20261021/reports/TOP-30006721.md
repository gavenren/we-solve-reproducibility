# Square-root-space time simulation: an exponential-time specialization with exact quantifiers

Problem: TOP-30006721  
Claim type: Literature report  
Author: /root/hundred_algorithms

**Exact scope.** Williams’s 2025 multitape simulation TIME(t) ⊆ SPACE(√(t log t)) is credited, specialized to every fixed exponential bound, and used with the space hierarchy to derive the known fixed-exponent time lower bound for linear space. Neither the full-union PSPACE/EXPTIME equality nor separation is claimed.

**Checked theorem.** Ryan Williams, Theorem 1.1 in the 25 February 2025 author manuscript, proves for every t(n)≥n that TIME[t(n)]⊆SPACE[√(t(n)log t(n))]. These classes use fixed multitape Turing machines, with O(t) time and O(s) work space. This is a deep simulation theorem, used as a literature result; its entire proof is not independently certified here. It does not assert the corresponding bound for arbitrary random-access machines.

The construction reduces time blocks of b transitions to an implicitly described constant-fan-in tree-evaluation instance of height O(t/b), whose node values have O(b) bits. The cited Cook–Mertz evaluation procedure costs O(b+(t/b)log b) space at this parameter level. Balancing b against the second term gives b of order √(t log t). Generating the correct tape blocks and their local evaluators within that space is part of Williams's theorem, not a consequence of this heuristic parameter calculation alone. In particular, simply drawing the exponentially large computation tree would not supply the theorem.

For a fixed integer k≥1 and t(n)=2^{n^k}, the theorem gives the explicit bound
\[
 \mathrm{DTIME}(2^{n^k})\subseteq
 \mathrm{DSPACE}\bigl(n^{k/2}2^{n^k/2}\bigr).
\]
Machine-dependent constants in the time bound change constants in the space bound. This is a square-root saving in the exponential quantity t, but the resulting space remains larger than every polynomial: n^k/2−C log₂n tends to infinity for each fixed C. Taking the union over k therefore does not turn this containment into EXPTIME⊆PSPACE. It only gives a quantitatively improved exponential-space simulation of each fixed time class.

There is nevertheless a genuine hierarchy consequence. First fix 0<ε≤1, so t(n)=n^{2−ε} satisfies the imported theorem’s hypothesis t(n)≥n. If every language in SPACE(n) were decidable in TIME(n^{2−ε}), then the theorem would place every such language in SPACE(n^{1−ε/2}√log n). For sufficiently large n this is contained in SPACE(n^{1−ε/4}), contradicting the deterministic space hierarchy, since n^{1−ε/4}=o(n) and both power bounds can be replaced by standard constructible integer bounds. Hence SPACE(n) is not contained in TIME(n^{2−ε}). For 1<ε<2, TIME(n^{2−ε}) is contained in TIME(n); the already proved ε=1 case therefore gives the same noncontainment without applying Williams’s theorem below its linear-time hypothesis. The witness language can depend on ε in this argument. The source additionally supplies a common complete-problem formulation; the elementary deduction here does not silently interchange ∀ε∃L with ∃L∀ε.

**Relation to the literal question.** PSPACE is contained in EXPTIME by configuration counting, as the earlier attempt proves. The new cited algorithm improves time-to-space simulation and yields a polynomial-exponent separation, but it supplies no language outside the union of all polynomial space bounds and no polynomial-space simulation of arbitrary exponential time. Any claim settling the original equality still requires one of those genuinely stronger conclusions.
