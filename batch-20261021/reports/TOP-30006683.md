# Simon search: explicit quantum success and adaptive classical lower bounds

Problem: TOP-30006683  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** For uniformly randomly labeled Simon oracles on n-bit addresses, O(n+log(1/delta)) quantum queries recover the hidden XOR with failure<=delta, while classical randomized search needs Omega(2^(n/2)) queries for constant average success. Full finite-distribution and adaptive-transcript proofs are supplied; this is an oracle/promise result and does not separate ordinary BQP from BPP.

For n>=1 choose s uniformly from the2^n-1 nonzero strings. Partition {0,1}^n into pairs {x,x+s}. Assign distinct n-bit labels to these pairs uniformly without replacement and define f to be the pair label. Access is through the usual reversible query |x,b>->|x,b+f(x)>. This distribution, not the list of f values or a succinct circuit description, is the input interface. Simon's established quantum/oracle result motivates the following complete quantitative calculation.

**Quantum output law.** Start with2^{-n/2}sum_x |x>|0>, query f and measure/discard the label register. Each resulting address state is (|x>+|x+s>)/sqrt2. A Hadamard transform on all n address qubits has support precisely on s-perp={y:y dot s=0}, and its measured distribution is uniform there. Indeed its amplitude at y is proportional to (-1)^{x dot y}(1+(-1)^{s dot y}); the magnitude is constant for y in s-perp and zero elsewhere. Fresh runs give independent uniform equations.

After t such queries, the probability that the measured vectors fail to span the(n-1)-dimensional space s-perp is at most
\[
 (2^{n-1}-1)2^{-t}<2^{n-1-t}.                            \tag{7}
\]
For if the span is proper, it lies in one of that space's2^{n-1}-1 codimension-one linear subspaces; all t samples lie in a fixed such subspace with probability2^{-t}. When the span is full, Gaussian elimination gives the one-dimensional orthogonal complement {0,s}; output its nonzero vector. With t=n-1+ceil(log_2(1/delta)) and an extra query if necessary for a strict endpoint convention, failure is at most delta. A rank-deficient sample is recognized as failure rather than an uncertified answer. Linear algebra and reversible/Hadamard gates have cost polynomial in n and t. For n=1 the only possible s is known without querying.

**Adaptive classical transcripts.** A repeated query adds no information, so assume q distinct queried addresses. Conditional on a transcript with no repeated label, a secret s is possible exactly when it is not a pairwise difference of two queried addresses. Conditional labels have the same distribution of fresh distinct random strings for every possible s: random pair labels supply no further preference. Consequently, even for an adaptive deterministic strategy, the posterior secret is uniform on the nonexcluded set. The chosen addresses may depend on labels, but the posterior assertion remains valid by induction over this transcript-generation process.

Let M=2^n-1 and B=binomial(q,2), and suppose B<M. Before query j, at least M-B secrets remain. At most j-1 of them cause the new address to pair with an earlier address and thus create a collision. A union bound gives
\[
 \Pr[\text{a collision among the q queries}]\le B/(M-B).
\]
On the no-collision branch, any one final guess succeeds with conditional probability at most1/(M-B). Hence, allowing the algorithm arbitrary computation and granting success on every collision transcript,
\[
 \Pr[\text{correct }s]\le (B+1)/(M-B).                  \tag{8}
\]
The same bound holds after averaging over an algorithm's internal random coins. It is deliberately loose but sufficient: if q=o(2^{n/2}), the success tends to zero. A constant average success therefore requires q=Omega(2^{n/2}). The lower bound is distributional over both secrets and random injective pair labels; it is not a claim about every specially structured oracle satisfying the collision promise.

**Why the interface matters.** The earlier attempts explain how a linear oracle or an explicit truth table can be easy. Formula(8) shows the exact missing premise: those structured labelings do not have the uniform conditional transcript law above. Giving the whole table has input size n2^n, against which classical exhaustive processing is polynomial; giving a circuit permits inspection of its syntax. No conversion of(8) into hardness against such algorithms is asserted. This is meaningful quantitative progress inside the query model, with full success probabilities, while the literal unrelativized separation remains unresolved by it. The algorithmic and lower-bound ideas are established Simon results, not new priority claims.
