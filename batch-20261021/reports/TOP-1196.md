# Local finite models force two-sided inverses for injective cellular automata

Claim type: **Partial result**.

We prove surjunctivity for **every group locally embeddable in finite groups**, including groups of arbitrary cardinality. The proof constructs a finite-memory left inverse and transports a single composition identity to a finite group, where it becomes two-sided. It does not require a global finite quotient of the original group. This is a self-contained proof of a known approximation-class result, not a claimed new solution of the universal conjecture.

A group$G$ is LEF if every finite subset$F\subset G$ containing$1$ admits an injection$\theta:F\to Q$ into a finite group, with$\theta(1)=1$ and $\theta(ab)=\theta(a)\theta(b)$ whenever$a,b,ab\in F$. No homomorphism on all of$G$ is required. Let$A$ be a nonempty finite alphabet and let$\tau$ be the injective automaton of the exact prompt, with memory$M$. Add$1$ to$M$ if necessary, ignoring that coordinate in its local rule$\mu$.

**Finite reconstruction.** There is a finite$N\subset G$, containing$1$, such that
\[
 \tau(x)|_N=\tau(y)|_N\quad\Longrightarrow\quad x(1)=y(1). \tag{1}
\]
Otherwise for every finite$N$ there would be$x_N,y_N$ agreeing after$\tau$ on$N$ but differing at$1$. In the compact space$A^G\times A^G$, the closed conditions$x(1)\ne y(1)$ and$\tau(x)(g)=\tau(y)(g)$ for$g\in G$ would have the finite-intersection property. A common point would contradict injectivity. This uses compactness, not sequential compactness, and hence is valid even when$G$ is uncountable.

Define$\nu$ on each pattern$\tau(x)|_N$ by$\nu(\tau(x)|_N)=x(1)$; (1) makes it well-defined. Extend$\nu$ arbitrarily to the remaining finitely many patterns in$A^N$. Its automaton$\sigma$ satisfies
\[
 \sigma\tau=\mathrm{id}_{A^G}. \tag{2}
\]
To see this at$g$, apply the defining reconstruction to the translated configuration$z(h)=x(gh)$; the right-memory convention in the prompt gives$\tau(z)(n)=\tau(x)(gn)$. This also fixes the order of every memory product below.

Take the finite set
\[
 F=\{1\}\cup M\cup N\cup NM\cup MN
\]
and an LEF embedding into$Q$. Define$\tau_Q$ and$\sigma_Q$ using the same local rules, replacing each memory label$m,n$ by$\theta(m),\theta(n)$. Because $\theta(nm)=\theta(n)\theta(m)$ and$\theta$ is injective on$NM$, the local expression for$\sigma_Q\tau_Q$ at$q\in Q$ is exactly the expression for$\sigma\tau$ on the corresponding finite$NM$ pattern. Every pattern on$NM$ extends to a configuration on$G$. Equation(2) therefore gives$\sigma_Q\tau_Q=\mathrm{id}_{A^Q}$ at every$q$.

The finite set$A^Q$ has equal finite domain and codomain, so$\tau_Q$ is bijective and$\tau_Q\sigma_Q=\mathrm{id}$. In the reverse composition the memory labels are$mn$, rather than$nm$. The inclusion$MN\subset F$ ensures both multiplication consistency and injectivity for these labels too. Given any pattern on$MN$, assign its values to the distinct positions$\theta(MN)$ in$Q$ and extend arbitrarily to$Q$. The finite identity then implies that the local expression for$\tau\sigma$ returns the central symbol for every such pattern on$G$. Hence
\[
 \tau\sigma=\mathrm{id}_{A^G}.
\]
Thus every target has the preimage$\sigma(y)$ and$\tau$ is surjective. The singleton alphabet is included, with the same argument or directly.

For example every residually finite group is LEF: choose finite quotient homomorphisms separating all pairs in$F$, and take their finite product. Every locally finite group is LEF by embedding$F$ in the finite subgroup it generates. The argument also covers local finite models not arising from any quotient; a quotient-based periodic-point proof alone would not establish that scope.

The finite reconstruction window depends on injectivity and is not given by an algorithm here. Compactness does not provide a uniform size bound in terms of$|M|$. No conclusion for arbitrary groups without the approximation hypothesis, or for infinite alphabets where the compactness and finite-set step fail, is asserted.
