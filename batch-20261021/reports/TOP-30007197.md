# The Kervaire obstruction from any nontrivial finite quotient

Claim type: **Literature report**.

Suppose $A$ has a nontrivial finite quotient. Then **every** $w\in A*\langle t\rangle$ fails to normally generate the free product. Only one nontrivial finite quotient is required; $A$ need not be finite, residually finite, finitely generated or torsion-free. This supplies an affirmative case including groups with finite perfect quotients, where a nontrivial abelianization argument alone would not suffice.

Let $e\in\mathbb Z$ be the exponent sum of$t$ in$w$ and let $Q=(A*\langle t\rangle)/\langle\!\langle w\rangle\!\rangle$. Killing$A$ maps this quotient onto
\[
 \langle t\mid t^e=1\rangle.
\]
For $e=0$ this is infinite cyclic; for $|e|\ge2$ it is a nontrivial finite cyclic group. Hence those cases hold for every coefficient group whatsoever. The sign and the case$e=0$ must be separated; writing a cyclic group of “order$e$” without conventions would obscure the latter case.

It remains to treat $e=\pm1$. Choose a surjection $q:A\twoheadrightarrow B$ with$B$ finite and nontrivial. The image$\bar w\in B*\langle t\rangle$ still has exponent sum$e$. The Gerstenhaber–Rothaus extension theorem [1, Theorem2] states that a square system over a finite group with nonzero exponent determinant has a solution in a finite overgroup containing that group. Applied to this one equation, it gives an inclusion $B\hookrightarrow C$ and an element$s\in C$ with$\bar w(B,s)=1$. Map$A$ to$C$ through$q$ and$t$ to$s$. The map kills$w$, so factors through$Q$. Its image contains the embedded nontrivial group$B$, proving$Q\ne1$.

The use of Theorem2 is accurately scoped: it guarantees an overgroup of$B$, not necessarily a solution **inside**$B$. For example an equation demanding a new root may not have an internal solution, although the coefficient group still embeds in a larger solution group. Finite generation of$A$ is irrelevant because all its coefficients pass through the single finite quotient$B$.

There is also a direct connected-Lie version of the last step. Embed$B$ faithfully by permutation matrices in$\mathrm U(|B|)$. The degree theorem [1, Theorem1] for the coefficient word map has degree $e^{|B|}$, nonzero for$e=\pm1$, and therefore supplies$s$ in that unitary group. This already proves nontriviality; the stronger finite-overgroup conclusion follows from the algebraic specialization/reduction argument in Theorem2. We do not need an effective bound on$|C|$, and none is claimed.

This proves in particular that a counterexample to the literal prompt, if one exists, must have a coefficient group with **no nontrivial finite quotient** and must use an exponent-$\pm1$ relator. The first restriction is stronger than saying merely that the coefficient group is not residually finite: many non-residually-finite groups still have a nontrivial finite quotient and are covered here. If$A$ has any nontrivial finitely generated residually finite quotient, it has a nontrivial finite quotient, so the same conclusion applies. An infinite simple group without finite quotients is not addressed by this argument.

The earlier A1 summarizes a claimed arbitrary-group Kervaire theorem and a coefficient-injectivity comparator without verification. The present proof uses only the checked classical finite-group equation theorem, and does not convert that summary into a certified general answer. It also distinguishes the prompt's weaker nontriviality conclusion from coefficient injectivity: the composite $A\to Q\to C$ need not be injective because$q$ need not be.
