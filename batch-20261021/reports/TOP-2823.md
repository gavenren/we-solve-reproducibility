# Ordered bending measures determine a non-Fuchsian punctured-torus group

**Problem:** TOP-2823

**Claim type:** Literature report

**Exact scope:** Part (b) is affirmative when S is a once-punctured torus, by Series's bending-measure uniqueness theorem for marked quasifuchsian groups with ordered ends. The report explains the fixed-pleating-locus monotonicity argument and separates actual measured data from projective supports. It does not settle part (a) or higher-complexity punctured surfaces.

Take \(S\) to be the once-punctured torus. Work with the marked representations modulo conjugacy and the ordered boundary components in the prompt. Series proves that the pair of bending **measures** determines a non-Fuchsian quasifuchsian representation. This is a genuine special-surface solution to part (b), credited to that theorem.

Here is the logical mechanism, useful for distinguishing the hypotheses. Write the two measures as \(a\mu,b\nu\), with \(a,b>0\) and fixed measured representatives of their projective classes. They have positive intersection. Any representation with these data lies in the ordered pleating locus \(\mathcal P(\mu,\nu)\). Series's Theorem 3.1 supplies length coordinates there. Inside it impose the first scale \(a\). Proposition 6.4 describes the resulting locus \(V_a\) as a single curve, and Proposition 7.1 proves that the second scale is strictly monotone on it. Therefore a given value \(b\) is attained at most once. This is the uniqueness required by injectivity; existence for arbitrary proposed input data is a different question.

The passage from rational to irrational laminations is not justified by density alone. A continuous map can be injective on a dense subset and fail to be injective: the circle parametrization on the real line, restricted to a suitably chosen dense set containing at most one representative of each period class, illustrates the logical issue. In the cited proof, convergence and compactness control the representations, and strict monotonicity survives through a separate nonconstancy argument. Those are substantive analytic inputs, not supplied here as new proofs.

Keeping the scale factors matters. Projective supports specify a two-real-dimensional pleating locus; the bending weights further specify its point. Likewise dropping the order of the two ends changes the equivalence relation. We retain both labels and the original marking.

Finally, exclusion of the Fuchsian locus is mathematically necessary. If bending measures were extended there by zero, all Fuchsian structures would have the same pair \((0,0)\), while their intrinsic metrics vary. The prompt already makes exactly this exclusion. No analogous conclusion for the two intrinsic-metric data in part (a), or for every punctured surface, follows from the once-punctured-torus argument.
