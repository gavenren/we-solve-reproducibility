# An exact reduction to finite periodic witnesses

Use the centered-cube upper density in the earlier record:
\[
\theta_T(K)=|K|\inf_{K+X=\mathbb R^n}
\limsup_{R\to\infty}\frac{|X\cap[-R,R]^n|}{(2R)^n},
\]
where$X$ is locally finite. For every full-dimensional compact convex$K$, the same infimum is obtained using only$X=F+L\mathbb Z^n$ with$F$ finite and$L>0$. Moreover rational finite patterns suffice if an arbitrarily small dilation of$K$ is allowed. No symmetry is needed for these reductions.

One direction is immediate because periodic coverings are allowed. For the converse fix a covering$X$ of finite upper density$d$, and choose$D$ with$K\subset[-D,D]^n$. For a large$R$, put
\[
F_R=X\cap[-R-D,R+D]^n.
\]
It is finite. Every point of$[-R,R]^n$ is covered by$K+F_R$, since any center covering it differs from it by a point of$K$. Repeat this finite pattern with period$2R$ in every coordinate. The translated closed cubes cover space, so$K+(F_R+2R\mathbb Z^n)=\mathbb R^n$.

Its center density is at most$|F_R|/(2R)^n$; coincidences modulo the period can only lower that density. By the definition of limsup,
\[
\limsup_{R\to\infty}|F_R|/(2R)^n\le d,
\]
because replacing$R$ by$R+D$ changes the denominator by a factor tending to one. Thus for every$\eta>0$ a periodic covering has density at most$|K|d+\eta$. Taking the infimum over$X$ proves equality. This argument controls the boundary halo explicitly; simply repeating centers from inside$[-R,R]^n$ would leave boundary holes.

Here is a precise rationalization statement. Translate$K$ so$\rho B_2^n\subset K$. For a periodic covering$F+L\mathbb Z^n$, choose a rational$L'>0$ close to$L$, and scale the entire pattern by$a=L'/L$. It covers$aK$. Because$K$ contains zero, if$a\le1+\varepsilon/2$ then$aK\subset(1+\varepsilon/2)K$. Round the finitely many scaled representatives$aF$ to rational points within Euclidean error$\varepsilon\rho/2$, keeping period$L'$ fixed. Every point formerly covered by$aK$ is now covered by
\[
aK+(\varepsilon\rho/2)B\subset(1+\varepsilon)K.
\]
The rounded periodic set therefore covers with the slightly dilated body. Choosing$a$ and the rounding arbitrarily close to their original values controls the density continuously, including the factor$(1+\varepsilon)^n$. Coincident representatives again only help the density.

The earlier contribution states an unverified full worst-case$n\log n$ lower claim and merely mentions periodization in its outline. This report provides the complete boundary-controlled and rational witness reductions needed to turn an all-coverings obstruction into a periodic-pattern obstruction. It does not produce the required hard bodies. In particular a finite pattern search at bounded period or bounded cardinality cannot certify the universal lower bound: the reduction imposes no uniform bound on either parameter.
