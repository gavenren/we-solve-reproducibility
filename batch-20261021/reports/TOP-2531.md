# Published group-ring criterion and unconditional nilpotent-base wreath classes

Claim type: **Literature report**.

There is a substantial published obstruction to treating the prompt as an automatic closure property. Bradford and Fournier-Facio [1, Theorems1.3,1.5 and1.12] connect even its abelian-base restriction to Kaplansky finiteness. This report records the exact criterion, derives concrete classes, and proves directly how a one-sided matrix inverse would obstruct Hopficity. The arbitrary epimorphism in the prompt is not assumed to preserve its base.

Write a finitely generated abelian base as
\[
 A=\mathbb Z^r\oplus\bigoplus_p\bigoplus_{i\ge1}(\mathbb Z/p^i\mathbb Z)^{d_{p,i}},
 \qquad m_p=\max_i d_{p,i}.
\]
For nontrivial $A$ and finitely generated $\Gamma$, the published criterion is
\[
 A\wr\Gamma\text{ Hopfian}\iff
 \Gamma\text{ Hopfian and }M_{m_p}(\mathbb F_p[\Gamma])
 \text{ directly finite for every }p\text{ occurring in }A. \tag{1}
\]
Primes not occurring impose no condition. A ring is directly finite when $XY=1$ implies $YX=1$; stable finiteness means this in every matrix size. The free rank contributes no positive-characteristic test. The trivial base must be separated: $1\wr\Gamma=\Gamma$.

Thus $A=\mathbb Z^r$, $r\ge1$, works for **every** finitely generated Hopfian $\Gamma$. For $A=C_p\oplus C_{p^3}\oplus C_{p^3}$ the sole ring test is size2 over $\mathbb F_p[\Gamma]$, not size4 or exponent3. By [1, Corollary1.6], every finitely generated abelian base works when $\Gamma$ is both Hopfian and sofic, or Hopfian and bi-orderable. Soficity alone does not replace the Hopfian hypothesis.

Moreover [1, Theorem1.12/5.5] treats a finitely generated nilpotent base $N$ via its upper central factors $Z_i/Z_{i-1}$. These are finitely generated abelian. If $\Gamma$ is finitely generated, sofic and Hopfian, the preceding criterion applies to each factor, and that published extension theorem yields $N\wr\Gamma$ Hopfian. This includes nonabelian nilpotent bases and does not rely on residual finiteness of the wreath product. These are credited deep results, not proofs supplied below.

Here is the explicit obstruction underlying the ring link. Let $R=\mathbb F_p[\Gamma]$, and let $X,Y\in M_d(R)$ satisfy $XY=I$ but $YX\ne I$. View the restricted base of $(C_p)^d\wr\Gamma$ as the additive group of column vectors $R^d$. Its elements have finite support. Left translation by $\Gamma$ acts by left multiplication on coefficients, so use the equivalent row-vector model and **right** multiplication by matrices: it commutes with this left action. Define $T(v)=vY$, $S(v)=vX$. Then $T(S(v))=vXY=v$, whereas $S(T(v))=vYX$ is not the identity map. Thus $T$ is surjective and noninjective: if it were injective, $TST=T$ would imply $ST=I$. Every matrix entry has finite group-ring support, so both maps preserve restricted support. Equivariance gives an epimorphism
\[
 (v,g)\longmapsto(T(v),g)
\]
of the wreath product with nonzero kernel. It is non-Hopfian. This verifies the obstruction without assuming that all possible endomorphisms have this form; the converse direction for arbitrary epimorphisms is precisely part of the published theorem.

Finally [1, Theorem1.3/4.11] proves that **all** finitely generated abelian-base, finitely generated Hopfian-actor wreath products are Hopfian if and only if Kaplansky's direct-finiteness conjecture holds for all groups and all fields. Universal direct and stable versions are equivalent, but a fixed ring's direct finiteness must not silently be replaced by all matrix sizes. The original prompt, which quantifies over arbitrary finitely generated Hopfian bases, would in particular settle that abelian-base assertion. The source supplies no general affirmative answer for all such bases, and neither does this report.
