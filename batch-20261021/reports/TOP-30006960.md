# Combinatorial Boolean multiplication from column interval runs

Problem: TOP-30006960  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** For Boolean n×n matrices and a given common row order for B, let κ be the total number of maximal one-runs in its columns. Full Boolean multiplication is deterministic in O(n²+nκ) logarithmic-word operations and O((n²+nκ)log(n+2)) bit time. In particular at most n^o(1) runs per column gives near-quadratic time on this subclass.

Read every column j of B in the given row order and store each maximal interval [ℓ,r] of one-entries. Empty columns have no intervals; boundary runs are included. Let κ be the total number of intervals. For each row i of A form prefix counts pᵢ(q)=Σ(k≤q)Aᵢₖ with pᵢ(0)=0. Set Cᵢⱼ=1 exactly if one of column j’s intervals satisfies
\[
 p_i(r)-p_i(\ell-1)>0 .
\]
Otherwise set it to zero.

A positive difference supplies a k with Aᵢₖ=Bₖⱼ=1. Conversely every Boolean witness lies in one of those intervals and makes its nonnegative prefix difference positive. This proves both directions, including all-zero rows/columns. Enumerating all witnesses is unnecessary.

Building intervals and prefixes costs O(n²) operations. For one A row, testing the intervals of all columns costs O(n+κ); over n rows the full cost is O(n²+nκ), including all output positions. Endpoints and prefix counts fit O(log(n+2))-bit words. The algorithm uses input inspection, bounded integer addition/subtraction, comparisons and output writes; no algebraic matrix or tensor method occurs. A conservative bit simulation charges O(log(n+2)) per operation. This is an upper bound even when the inputs are bit-packed.

Process A one row at a time. Apart from the n²-bit inputs and full output, only O(n+κ) words are needed for current prefixes and interval endpoints. There is no need to retain n² prefix counts. A supplied common permutation of B’s rows is permitted if A’s columns are permuted inversely, at O(n²) extra cost. Finding a best permutation is a different problem and is not assumed.

If each column has at most k runs, κ≤nk, so the bound is O(n²(1+k)). Consecutive-one columns give quadratic time for arbitrary A; k=n^o(1) gives n^(2+o(1)). All n distinct row and column types can occur in this family.

Indeed take A=J−I and Bₖⱼ=1 iff k≤j. A’s rows and B’s columns are all distinct, and the total witness mass is
\[
 \sum_k(n-1)(n-k+1)=(n-1)n(n+1)/2=\Theta(n^3).
\]
The earlier equal-type intersection bound and explicit witness enumeration have cubic (up to word factors) expressions here. Yet κ=n and the present algorithm is quadratic. This comparison separates the parameter guarantees, not the intrinsic hardness of these particular matrices.

For arbitrary B, alternating column bits give κ=Θ(n²), so the method can be cubic. Simply decomposing columns into intervals does not prove the unrestricted near-quadratic conjecture: the number of pieces must be paid. The new tractable parameter and its preprocessing are fully explicit.
