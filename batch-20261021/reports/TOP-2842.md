# Finite multiplicity obstructions to fillability of a specified planar open book

**Problem:** TOP-2842

**Claim type:** Partial result

**Exact scope:** For a fixed planar open book, Wendl's theorem converts strong/Stein fillability into positive allowable factorization of that same monodromy. The report proves an effective finite nonnegative-integer obstruction using annular and pairwise multiplicities, with an explicit infinite family ruled out. This is a one-sided obstruction, not a general tightness or fillability decider; weak fillability is not covered.

Let the page be a disk with \(n\ge2\) labeled holes and let \(\phi\) fix every boundary component. Wendl's planar theorem gives the following exact import: the supported contact structure is strongly fillable if and only if this particular monodromy admits a positive allowable Dehn-twist factorization. Here allowable means each vanishing curve is homologically nontrivial. Strong and Stein fillability coincide for planar contact manifolds; exact fillability lies between them and hence is equivalent as an existence property in this class. Weak fillability is kept separate.

There is a finite, effective obstruction to such a factorization. For each hole \(i\), cap all other holes to obtain an annulus; the induced mapping class is an integer power of its positive core twist. Denote this integer by \(h_i(\phi)\). For each pair \(i,j\), replace these holes by punctures and fill the others, obtaining a pure two-strand braid; write \(l_{ij}(\phi)\) for its full-twist exponent. These are homomorphisms, computable by adding the contributions of the twists in the supplied word.

If a simple curve encloses the nonempty subset \(A\) of holes, a positive twist about it contributes \(1\) to \(h_i\) precisely for \(i\in A\), and \(1\) to \(l_{ij}\) precisely for \(\{i,j\}\subseteq A\). It contributes zero otherwise. This follows by capping or forgetting holes: it becomes a core twist, a full twist on the retained pair, or a trivial twist, respectively.

Therefore any allowable positive factorization supplies nonnegative integers \(c_A\), one for each nonempty \(A\subseteq\{1,\ldots,n\}\), satisfying
\[
 h_i(\phi)=\sum_{A\ni i}c_A,\qquad
 l_{ij}(\phi)=\sum_{A\supseteq\{i,j\}}c_A.
\]
These constraints can be tested by finite enumeration. A negative \(h_i\) rejects immediately. Otherwise put \(H=\sum_i h_i\). Summing the first equations shows
\(\sum_A|A|c_A=H\), so each \(c_A\le H\) and the number of positive factors is at most \(H\). Enumerate the finitely many vectors in \(\{0,\ldots,H\}^{2^n-1}\) and test the displayed equalities. Failure proves no strong, exact or Stein filling exists.

For an explicit family, take \(\phi=T_\gamma^{-k}\prod_i T_{\delta_i}^{r_i}\), where \(k\ge1\), \(\gamma\) encloses at least two holes, \(\delta_i\) encloses only hole \(i\), and \(r_i\) are arbitrary integers. For any pair inside \(\gamma\), \(l_{ij}(\phi)=-k\), which contradicts the nonnegative sum. Boundary twists cannot repair this obstruction.

Success of the integer test does not establish fillability. Curves enclosing identical hole subsets can have different isotopy classes, and the ordered product must still equal \(\phi\) in the nonabelian mapping class group. Finite multiplicity possibilities do not make the set of curves finite. Thus this result supplies genuine finite negative certificates for a specified input and a nonfillable family, while leaving the full halting decision and tightness question unresolved.
