# A factorization-free square-class-rank parameter for exact square-root sums

Problem: TOP-3399  
Claim type: Partial result  
Author: /root/hundred_algorithms

**Exact scope.** An unconditional exact algorithm decides binary square-root-sum instances in 2^{O(r)}poly(L) bit time, where r is the F₂-rank of the positive radicands in Q*/Q*²; this rank is itself discovered within that bound using integer-square tests, without integer factorization or supplied prime factors. In particular r=O(log L) gives polynomial time. Equality remains a yes-instance.

Discard zero radicands. Greedily maintain a list u₁,…,u_r of previously encountered positive radicands. Given a new a, enumerate every subset J⊆[r], put P_J=∏_{j∈J}u_j, and test whether aP_J is an integer square by an exact integer square root. If so, a represents the product of those square classes and does not enlarge the list; otherwise append a. This is precisely Gaussian-basis selection in the elementary abelian group Q*/Q*², implemented by enumeration rather than factorization: positive integers a and P have the same rational square class exactly when aP is an integer square. Indeed a/P=(z/P)² if aP=z²; conversely a/P rational-square implies the integer aP is a rational square, hence an integer square by reducing numerator and denominator. The final list has rank r and generates every radicand class.

All u_j are distinct entries selected from the input, so the bit length of any P_J is at most the sum of the input radicand lengths, at most L. Each test uses integers with O(L) bits. At most n·2^r such tests, each with polynomial bit cost, discover the rank. This does not enumerate primes or invoke an uncharged factoring subroutine.

Every square root √a_i belongs to K=Q(√u₁,…,√u_r), since a_iP_J=z² gives √a_i=(z/P_J)√P_J with nonnegative z. The field degree D is at most 2^r, by adjoining the r generators successively; equality of the degree is unnecessary. Write α=k−Σ_i√a_i, an algebraic integer, and set the easily computed integer
\[
 B=\max(1,k+\sum_i a_i).
\]
Because √a_i≤a_i for positive integer a_i, every conjugate of α has absolute value at most B. If α≠0 its norm from K is a nonzero integer, whence
\[
 |\alpha|\ge B^{-(D-1)}\ge B^{-(2^r-1)}.
\]
No assumption that every sign pattern is an actual embedding is used. Let C be the binary length of B, q=C(2^r−1), and p=q+⌈log₂(n+1)⌉+2. Compute z_i=⌊√(a_i2^{2p})⌋ exactly and put A=Σ_i z_i. The interval [A2^{-p},(A+n)2^{-p}] contains the sum and has width n2^{-p}<2^{-q}. If its lower endpoint exceeds k, answer no. If its upper endpoint is at most k, answer yes. Otherwise it contains k and forces |α|<2^{-q}; the nonzero separation bound excludes that case unless α=0. Answer yes. Empty input and r=0 are covered: all remaining radicands are squares and q=0 is harmless; direct integer addition is an optional shortcut.

The precision p is O(2^r(L+log(n+1))). Integer square roots, additions, products and comparisons at that precision take polynomial bit time and space. Together with basis discovery, this proves 2^{O(r)}poly(L) bit time and space. Intermediate shifted integers and output intervals are explicitly charged; arbitrary real arithmetic is not unit cost.

The earlier attempt used the universal degree 2^n. Its observation that instance degree information might help did not supply a way to discover such information. Here the parameter is discovered without a prime-factor oracle, can be logarithmic even with arbitrarily many summands, and yields a proved polynomial-time subclass. For example any list a_i=b_i²u or b_i² with one fixed positive u has r≤1, regardless of the number and binary sizes of the b_i. More generally the subgroup can have r generators even if individual radicands have many prime factors. The unrestricted variable-rank P and NP questions are not settled.
