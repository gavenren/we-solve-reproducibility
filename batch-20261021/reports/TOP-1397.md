# Mixed multibrooms and an explicit forest-extension recurrence

**Claim type: Literature report.** The prompt's \(\chi\)-boundedness conclusion is known for every tree formed by identifying the handles of finitely many brooms whose handle-to-branch lengths are one or two. We state the exact Scott–Seymour theorem used, explain its application to arbitrary such branch sizes, and prove a quantitative recurrence extending the result to disconnected forests with these components. This is credited established theory, not a solution for arbitrary fixed trees.

## Exact external theorem and shape

A broom of length \(j\ge1\) is a \(j\)-edge path with endpoints \(a,b\), together with some pendant leaves added at \(b\); \(a\) is the handle. A multibroom identifies only the handles of several otherwise disjoint brooms. In particular, the path length counts edges before the extra leaves, and all cross-branch pairs remain nonadjacent.

Scott–Seymour, *Induced subgraphs of graphs with large chromatic number. XIII. New brooms*, arXiv1807.03768v1, Theorem1.2, uses the following universal tree \(T(\delta)\). It has \(\delta\) brooms of length one and \(\delta\) of length two, each with \(\delta\) added leaves, and all handles identified. For every fixed \(\delta\) and clique bound \(w\), there is a finite \(c(\delta,w)\) such that every graph with no induced \(T(\delta)\) and clique number at most \(w\) has chromatic number at most \(c(\delta,w)\).

The finite bound is independent of the order of the host graph. The theorem is a deep external input; the report does not reproduce its whole structural proof or turn its existence statement into a claimed polynomial estimate.

## Applying the universal shape without reversing containment

Let \(T\) be any fixed mixed multibroom of lengths one and two. Choose an integer \(\delta\) at least the number of branches of each length and the largest number of pendant leaves on a branch. Select the needed branch paths in \(T(\delta)\), select the required number of their leaves, and discard unused branches and unused leaves. The selected vertices induce exactly \(T\). The construction does not contract an edge or permit an unwanted cross-branch edge.

If a host \(G\) is \(T\)-free, then it is \(T(\delta)\)-free: an induced \(T(\delta)\) would contain the just-described induced \(T\). Thus \(c(\delta,w)\) is a binding function for \(T\). The implication would be wrong in the opposite direction. Taking a maximum over smaller \(w\), and rounding to integers, lets us choose a nondecreasing binding function \(B_T(w)\) with \(B_T(0)=0\).

This class includes arbitrarily many branching vertices, branches of both lengths, and unbounded leaf multiplicities. It is substantially larger than the stars and paths of order at most three handled in the earlier attempt.

## A complete quantitative extension from trees to forests

The following lemma applies to any finite list of trees for which binding functions are known, not only multibrooms.

Let \(F=T_1\sqcup\cdots\sqcup T_r\), and suppose \(B_i(w)\) bounds \(\chi\) on \(T_i\)-free graphs of clique number at most \(w\). Then there is a binding function \(C_F\) for induced \(F\)-free graphs. An explicit recursive choice is as follows. Set \(C_F(0)=0\); for a single component take \(C_{T_i}=B_i\). For \(r\ge2\), write \(F'=T_2\sqcup\cdots\sqcup T_r\), \(t=|V(T_1)|\), and define successively in \(w\ge1\)
\[
 C_F(w)=
 \max\left\{B_1(w),\
 t\bigl(1+C_F(w-1)\bigr)+C_{F'}(w)\right\}. \tag{1}
\]
The right side is well-defined by induction first on the number of components and then on \(w\).

To prove it, let \(G\) be \(F\)-free with \(\omega(G)\le w\). If \(G\) is \(T_1\)-free, use \(B_1(w)\). Otherwise fix an induced copy \(A\cong T_1\). Each neighborhood \(G[N(v)]\), \(v\in A\), is still \(F\)-free and has clique number at most \(w-1\): adjoining \(v\) to a clique in its open neighborhood raises clique size by one. By induction its chromatic number is at most \(C_F(w-1)\).

Let \(Z=A\cup\bigcup_{v\in A}N(v)\). Color its constituent sets with separate palettes, giving
\[
 \chi(G[Z])\le t+tC_F(w-1).
\]
The bound is valid even though the sets overlap: assign each vertex to one constituent set containing it and restrict that set's coloring.

The remaining set \(R=V(G)\setminus Z\) is anticomplete to \(A\). It must be \(F'\)-free, because an induced \(F'\) in \(R\), together with \(A\), would induce \(F\), with all required cross-component nonedges. Hence \(\chi(G[R])\le C_{F'}(w)\). Using separate palettes for \(Z,R\) proves (1).

The base \(w=0\) is the empty graph. This also handles isolated-vertex components: a selected singleton is an induced \(T_1\), and the same closed-neighborhood argument applies. No erroneous assumption that all components already coexist without cross edges is made.

Applying this lemma to the credited mixed-multibroom theorem yields \(\chi\)-boundedness for every forest whose components have that shape. This is a genuine induced-forest statement; disjointly finding ordinary tree copies without controlling their cross edges would not prove it.
