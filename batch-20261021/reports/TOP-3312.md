# How terminal forest profiles produce the29- and52-vertex counterexamples

**Claim type: Literature report.** Cames van Batenburg, Goedgebeur and Jooken's24August2026 preprint reports explicit planar counterexamples to the literal half-order assertion, including a29-vertex graph with maximum induced forest14 and a52-vertex graph with maximum induced forest25 [1]. This report explains the exact gluing mechanism, not just the numerical announcement. The finite gadget profiles and their planarity are credited source inputs, not computations independently rerun here.

For a graph \(J\) with a distinguished edge \(uv\), define
\[
 p_J(X)=\max\{|F|:J[F]\text{ is a forest},\quad
 F\cap\{u,v\}=X\},\qquad X\subseteq\{u,v\}.
\]
Suppose graphs \(J_1,J_2\) are joined by identifying their distinguished edges and otherwise have disjoint vertices and no cross edges. Then
\[
 a(J_1\cup_{uv}J_2)
 =\max_{X\subseteq\{u,v\}}
   \bigl(p_{J_1}(X)+p_{J_2}(X)-|X|\bigr).
 \tag{1}
\]
Restriction of any induced forest proves the upper bound. For the reverse bound take maximizing forests with the same \(X\). If \(|X|\le1\), their union cannot create a cycle crossing the two pieces. If \(X=\{u,v\}\), each forest contains the edge \(uv\). A crossing cycle would force an alternative \(u\)-to-\(v\) path avoiding this edge in one piece, contradicting that this piece is a forest. Thus the union is an induced forest and(1) holds. The presence of the shared **edge** is important; arbitrary2-vertex gluing can create a new cycle.

The source's planar gadgets \(Q,R\) have orders14 and17 and profiles, in the order \(\varnothing,\{u\},\{v\},\{u,v\}\),
\[
 p_Q=(6,7,7,7),\qquad p_R=(8,8,8,9).
 \tag{2}
\]
Equation(1) gives
\[
 a(Q\cup_{uv}R)=\max(14,14,14,14)=14.
\]
The graph has \(14+17-2=29\) vertices, so14 is below the required \(\lceil29/2\rceil=15\). Both gadgets can be embedded with their distinguished edge on the outer face; placing the pieces on opposite sides gives the planar edge-amalgam shown in the source. The report relies on the source's actual gadgets and profiles(2), rather than claiming that any planar graphs of these orders have these profiles.

For the larger obstruction take three disjoint copies \(R_i\), with terminals \(b_i,c_i\), and a new vertex \(z\). Keep their distinguished edges and add
\[
 zb_i,\ zc_i,\ b_i c_{i+1},\ c_i c_{i+1}
 \quad(i=1,2,3;\ \text{indices modulo }3).
 \tag{3}
\]
The source Figure5 gives a planar embedding. Let \(F\) induce a forest, let \(t\) count copies in which both terminals are selected, and let \(\varepsilon\) indicate whether \(z\in F\). By(2),
\[
 |F|\le24+t+\varepsilon.
\]
If \(\varepsilon=1\), no copy can have both terminals, since \(z,b_i,c_i\) form a triangle. If two copies have both terminals, choose their cyclicly successive indices \(i,i+1\); the three vertices \(b_i,c_i,c_{i+1}\) form a triangle by(3). Thus always \(t+\varepsilon\le1\), giving \(|F|\le25\). Conversely choose an8-vertex forest avoiding both terminals in each copy and include \(z\). All connecting edges then have an omitted endpoint, so the selected vertices induce three forests and an isolated vertex. Therefore \(a(G_{52})=25<26\).

Disjoint unions of \(k\) copies have \(52k\) vertices and forest number \(25k\), because forest number is additive across components. Adding edges in a planar triangulation on the same vertex set can only decrease the maximum induced-forest order. Hence there are planar triangulations with \(a(G)\le25|V(G)|/52\) at all orders \(52k\), as the source's Corollary4.2 states. This is an unbounded deficit, not a finite observation promoted without argument.

The paper's minimum-order assertion and its4-connected5-edge-connected examples use further exhaustive generation. Those computations were not rerun and are not needed for the profile-to-obstruction deductions above. The preceding attempt mentions29 and25/52 as context but supplies only elementary positive classes; it does not explain(1)–(3) or the terminal-dependence that makes the half-order bound fail.
