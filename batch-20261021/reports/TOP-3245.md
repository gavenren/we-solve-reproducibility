# Logarithmic list sizes when monochromatic conflict components are bounded

**Claim type: Partial result.** Let \(G\) be a finite bipartite graph with fixed bipartition \(A,B\), and assign each vertex a set \(L(v)\) of exactly \(k\) colors. For each color \(c\), let
\[
 G_c=G[\{v:c\in L(v)\}].
\]
Suppose every connected component of every \(G_c\) has at most \(F\) vertices. Then a proper list coloring exists provided
\[
 e\,2^{-k}\bigl(k(F-1)+1\bigr)\le1. \tag{1}
\]
In particular the explicit choice
\[
 k=\left\lceil2\log_2(F+1)+6\right\rceil \tag{2}
\]
suffices. The same holds for larger \(k\) under the corresponding component hypothesis.

This is a theorem for list assignments with a local overlap condition. It permits arbitrarily large connected graphs and arbitrarily many occurrences of one color. It does **not** assert that all \(k\)-lists have that condition, and so does not prove a bound on the unrestricted choice number.

## Refining the palette variables by actual conflicts

For each pair \((c,C)\), where \(C\) is a connected component of \(G_c\), choose an independent fair bit \(X_{c,C}\). Interpret bit zero as permitting color \(c\) on the \(A\)-vertices of \(C\), and bit one as permitting it on the \(B\)-vertices.

For a vertex \(v\), the \(k\) distinct colors in its list give \(k\) distinct independent variables, one for each color's component containing \(v\). Let \(E_v\) be the event that none of its \(k\) colors is permitted on its side. Then
\[
 \mathbb P(E_v)=2^{-k}. \tag{3}
\]
This construction differs materially from assigning just one global bit per color. A single color can use opposite palettes in separate components of \(G_c\), because no edge of \(G\) with that color available at both endpoints joins those components.

If all \(E_v\) are avoided, choose any permitted listed color at each vertex. Suppose an edge \(uv\), with \(u\in A,v\in B\), received the same color \(c\) at both ends. Since \(c\in L(u)\cap L(v)\), both endpoints lie in the **same** component \(C\) of \(G_c\). The bit \(X_{c,C}\) cannot permit \(c\) on both sides, a contradiction. Thus any such choice is proper.

## A valid degree bound for the event dependencies

An event \(E_v\) depends only on its \(k\) component variables. Each variable \(X_{c,C}\) occurs in events belonging to the at most \(F\) vertices of \(C\), so it is shared with at most \(F-1\) other events. Therefore \(E_v\) shares a variable with at most
\[
 D=k(F-1)
\]
other events. Any collection of events with disjoint variable sets from \(E_v\) is jointly independent of it, so this is a genuine dependency graph, not an inference from geometric distance or maximum graph degree.

The symmetric Lovász local lemma states that events of probability at most \(p\), with such a dependency graph of maximum degree \(D\), can all be avoided if \(ep(D+1)\le1\). With (3) this is exactly (1). The variable setting also fits the constructive Moser–Tardos framework: resample precisely the variables of a violated event. No implementation or runtime experiment is asserted here.

For clarity, the local lemma is an external credited probability theorem. Its general variable version and resampling theorem were checked in Moser–Tardos, arXiv0903.0544v3, Theorems1.1–1.2. All graph/list-specific dependency calculations are proved above.

## Checking the explicit logarithmic choice

Assume first \(F\ge2\), and let \(k\) be (2). The inequality \(\log_2(F+1)\le F\) gives
\[
 k\le2F+7\le4(F+1).
\]
Also
\[
 2^{-k}\le{1\over64(F+1)^2},\qquad
 k(F-1)+1\le4(F+1)^2.
\]
The left side of (1) is at most \(e/16<1\). For \(F=1\), \(D=0\), and (2) gives \(k=8\), again satisfying (1). As \(k2^{-k}\) and \(2^{-k}\) decrease for integer \(k\ge2\), every larger \(k\) satisfies the same numerical criterion for fixed \(F\).

If \(F\le\Delta^a\) for a fixed \(a>0\) and \(\Delta\ge2\), then (2) is at most
\[
 2a\log_2\Delta+9.
\]
Thus logarithmic-size lists suffice on this restricted local-conflict scale with a constant independent of graph order. This is an assignment-level sufficient condition, not a claim that degree bounds force \(F\le\Delta^a\).

## Why global color frequency and graph order may be unbounded

The hypothesis bounds each **connected conflict component**, not the total number of vertices using a color. Repeating identical list patterns on arbitrarily many separated color components leaves \(F\) unchanged, even if the underlying graph remains connected through edges whose endpoint lists share no such color.

For example, take an arbitrarily long path and give each consecutive pair of vertices its own disjoint \(k\)-color palette, using the same palette on both vertices of that pair. Across pair boundaries the palettes are disjoint. Every \(G_c\) is an edge or isolated vertices, so \(F\le2\), independently of the path length. Multiple distant pairs can reuse one palette as long as adjacent pairs do not; then its colors have unbounded total occurrence but still \(F\le2\). This example illustrates the hypothesis rather than serving as the substantive result, which covers all graphs/lists satisfying it.

## Exact gap closed and gap retained

The prior Math-1176-A1 manuscript proves a global palette union bound depending on the number of vertices and explicitly warns that a color can occur at arbitrarily many distant vertices, invalidating a degree-only local-lemma assertion. Here the refined component variables allow a correct local dependency calculation even with unbounded total color frequency.

The remaining obstruction is real: if all vertices of a large connected graph share a color, its \(G_c\) can have arbitrarily large order at fixed maximum degree. No estimate of \(F\) in terms of \(\Delta\) follows in general. Removing this additional assignment condition, while retaining logarithmic list sizes, is outside the proof.

The report is a complete deduction from the credited local lemma, with no novelty priority, finite computational evidence or unrestricted Alon–Krivelevich conjecture claim.
